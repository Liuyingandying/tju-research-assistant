## 字段详细说明

### title
- **Selector**：`.result-item h3 a.fw-bold`
- **提取方式**：`innerText.trim()`
- **示例**：`Terahertz Tomography for Non-Destructive Testing of Objects with Random Surfaces`

### authors
- **Selector**：`.result-item .author a`
- **提取方式**：`Array.from(el).map(a => a.innerText.trim())`
- **分隔符**：每个 `<a>` 一个作者，`<span class="separator">;</span>` 分隔（DOM 分开，无需自己分隔）
- **示例**：`["Kun Meng", "Liguo Zhu", "Zeren Li", "Hu Liu", "Yao Xu", "Hongzhang Chen"]`

### year
- **定位方式**：从结果项全部文本（`allText`）中正则 `\b(20\d{2})\b` 匹配，或从 `span` 文本 `Year: 2024` 提取
- **Selectors**：`span` 文本 `Year: 2024` 或 `item.innerText` 正则
- **示例**：`2024`

### venue
- **定位方式**：作者下方 `<p>` 文本，直接使用 `item.innerText` 中会议名称片段
- **示例**：`2024 49th International Conference on Infrared, Millimeter, and Terahertz Waves (IRMMW-THz)`

### url
- **Selector**：`h3 a.fw-bold` 的 `href`
- **提取方式**：`element.getAttribute('href')`
- **示例**：`/document/10697582/`（完整 URL 需拼接代理域的 `origin`）
- **完整 URL**：`https://<代理域>/document/10697582/`

### doi
- **状态**：❌ **搜索结果页不显示 DOI**
- **替代方案**：如需 DOI，需进入详情页获取（本阶段不进入详情页），或标记为 `None`

### abstract
- **状态**：⚠️ 搜索结果页显示的是会议元数据卡片（会议名称、年份、类型、出版社）而非传统摘要
- **内容**：`2024 49th International Conference on Infrared, Millimeter, and Terahertz Waves (IRMMW-THz)\nYear: 2024 | Conference Paper | Publisher: IEEE\nCited by: Papers (4)`
- **建议**：标注为 `None`，或使用该元数据文本作为摘要替代

### document_type
- **定位方式**：从 meta 标签 `Conference Paper` 提取
- **示例**：`Conference Paper`、`Journals & Magazines` 等

## 字段提取建议

```python
# 伪代码
item = page.locator(".List-results-items .result-item").first
title = item.locator("h3 a.fw-bold").inner_text()
url = item.locator("h3 a.fw-bold").get_attribute("href")
authors = item.locator(".author a").all_inner_texts()  # list
all_text = item.inner_text()
year = re.search(r"\b(20\d{2})\b", all_text)
venue = re.search(r"\d{4}\s+(.+?)\(", all_text)  # 会议名称
doc_type = "Conference Paper"  # 从文本匹配
```

## 字段缺失处理

- **DOI**：搜索结果页不存在，标记为 `None`
- **abstract**：搜索结果页显示的是元数据卡片而非摘要，标记为 `None` 或使用元数据文本
- 其余字段全部可提取，稳定性高（Bootstrap 类名稳定，Angular 动态类名在稳定的父类下）
