## 3. 主题检索（太赫兹）

- 路径：万方落地页 → 普通检索"太赫兹" → 结果页顶部页签 `专利`
  （页签列表证据：全部/期刊/学位/会议/专利/科技报告/成果/标准/法规/地方志/视频）。
- URL：`.../patent?q=太赫兹&p=1`
- 结果：**30,632 条**，20 卡片，前 3 标题：
  1. 一种基于太赫兹时域光谱的咖啡豆二组分混合物定量检测方法（发明公开）
  2. 太赫兹连续波风机叶片无损检测成像光路系统（发明授权）
  3. 基于光电开关控制的通道式太赫兹安检数据提取控制方法（发明授权）

## 4. 发明人检索（殷贤华，取自主题结果首条详情页真实发明人）

- 路径：`/advanced-search/patent` 高级检索，row0 字段切 `专利-发明/设计人`，
  模糊形态即可（无需论文作者那种精确模式修正）。
- 结果：**59 条**，20 卡片。
- 真实性核对：首条详情页 `发明/设计人：殷贤华 孙傲 李康 游骁璇 马政帅 田义山`
  → 命中条件 ✓（`probe_wanfang_patent_search.py` 输出 inventor_detail_check）。

## 5. 申请人检索（天津大学）

- 结果：**74,842 条**，20 卡片。

## 6. 五个核心字段获取率（PASS）

| 字段 | 来源 | 证据 |
| --- | --- | --- |
| title | 列表页 `.title-area span.title` | 卡片 HTML（04/12 json） |
| inventors 发明人 | 详情页 `发明/设计人`（每专利 1 次详情打开） | 07 json、inventor_detail_check |
| applicant 申请人 | 列表页 `span.authors`（专利行语义） | 12 json row HTML |
| publication_number | 列表页 `span.t-ML6` + `title-id-hidden`（`patent_ZL_申请号_公开号_日期`） | 04/12 json |
| date | 列表页 `applyDate`（申请日/公开日） | 12 json |
| url | 点击标题 → 详情新标签；URL 由 title-id-hidden 编码可重定位 | 06/07 json |
| abstract | 列表页 `abstract-area` | 12 json |
| application_number | `title-id-hidden` 第二段 / 详情页 申请/专利号 | 07 json |
| IPC / 法律状态 | 详情页 主分类号 / 列表页 发明公开·发明授权 | 07/12 json |

## 7. SPA / 授权稳定性

- 结果内联渲染于 `/advanced-search/patent?t=<ts>`（URL 提交前后不变，
  XHR 驱动重渲染）。
- **无陈旧渲染**：首次/再次 goto 高级检索页均 0 结果（13 json），
  提交后内容与条件一致——等待逻辑可简化为 titles>0 + loading 消失，
  无需论文路径的 signature-change 防御。
- 未触发验证码；同一授权会话 4 次独立探针运行全部 `logged_in`。

## 8. Adapter 预计成本（低-中）

- 列表页解析：6-7 个稳定 class 选择器（title/pre-publish·sync-publish/
  t-ML6/authors/applyDate/abstract-area/title-id-hidden），无新依赖。
- 发明人：每专利 1 次详情页打开解析（同既有 WanfangMetadataResolver 模式，
  可复用其超时/降级/缓存骨架，但字段/选择器独立）。
- URL：详情页由点击标题新标签获得；title-id-hidden 提供重定位标识。
- 检索：复用高级检索表单交互模式（row0 字段切换 + 逐键输入 + 回读 + 提交），
  字段选项含 发明/设计人、申请/专利权人、公开/公告号、申请/专利号、主分类号 等
  （10 json 选项全表）。
- 与 FilterService 契约（Phase 2.2-A）对齐：inventors→authors 镜像可选、
  applicant、date、publication_number、application_number。

## 11. 未来 PatentAdapter 最小设计（仅记录，未实施）

```python
SearchResult(
    title=...,               # 列表页 .title span
    authors=inventors,       # 可选镜像（UI 作者列兼容）；正式语义见 artifact_metadata.inventors
    year=...,                # 公开日/申请日年份
    source=...,              # 申请人 或 法律状态（演示展示用）
    database="万方专利",
    artifact_type="patent",
    artifact_metadata={
        "inventors": [...],           # 详情页 发明/设计人
        "applicant": "...",           # 列表页 span.authors
        "publication_number": "...",  # 列表页 t-ML6 / title-id-hidden
        "application_number": "...",  # title-id-hidden 第二段
        "date": "...",                # 公开日（优先）或申请日
    },
)
```

查询映射（站点语义已确认）：
- 研究方向 → 主题/题名/摘要 字段（高级检索"主题"）；
- 人员姓名 → `专利-发明/设计人`；
- 人员单位 → `专利-申请/专利权人`；
- 组合：三字段可并存于高级表单行（与论文高级检索行规划同构）。
