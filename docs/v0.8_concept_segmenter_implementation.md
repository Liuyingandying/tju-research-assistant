## 二、算法说明

### 2.1 核心思路：基于 `TERMS` 词典的最长匹配

`ConceptSegmenter.segment(text)` 从文本每个位置尝试匹配**最长**的 `TERMS` 词典词：

1. **命中最长词典词** → 切为一个概念，跳过该词长度；
2. **未命中** → 累积连续未命中字符为一段（避免逐字碎片，如 `通信` 不会切成 `通`+`信`）；
3. **未知词** → 整段保留（安全回退，不抛异常）；
4. **空白** → 视为概念边界，切分后 `strip()` 并丢弃空段（空白不构成概念）。

### 2.2 实现

```python
class ConceptSegmenter:
    def __init__(self, dictionary: set[str] | None = None) -> None:
        self._dict = set(dictionary) if dictionary else set()

    def segment(self, text: str) -> list[str]:
        if not text:
            return []
        raw: list[str] = []
        i = 0
        n = len(text)
        while i < n:
            matched = self._longest_match(text, i)
            if matched is not None:
                raw.append(matched)
                i += len(matched)
            else:
                start = i
                while i < n and self._longest_match(text, i) is None:
                    i += 1
                raw.append(text[start:i])
        concepts: list[str] = []
        for seg in raw:
            seg = seg.strip()
            if seg:
                concepts.append(seg)
        return concepts

    def _longest_match(self, text: str, start: int) -> str | None:
        for end in range(len(text), start, -1):
            if text[start:end] in self._dict:
                return text[start:end]
        return None
```

### 2.3 对两个问题的效果（`dictionary = {"太赫兹", "通感一体化"}`）

| 输入 | 切分结果 | 说明 |
| --- | --- | --- |
| `太赫兹通感一体化` | `[太赫兹, 通感一体化]` | 问题 1 解决：最长匹配 `太赫兹`（3 字）+ `通感一体化`（5 字） |
| `太赫兹通信` | `[太赫兹, 通信]` | 问题 2 部分解决：`太赫兹` 切出并翻译；`通信` 未命中保留为一段（待 `TERMS` 扩充 `通信`→`communication`） |
| `量子计算` | `[量子计算]` | 未知词整段保留（安全回退） |
| `太赫兹 通感一体化`（有空格） | `[太赫兹, 通感一体化]` | 与最长匹配一致（向后兼容） |

## 三、架构变化

### 3.1 调用链变化

```
QueryTranslator._concepts_for(expanded)
  原：expanded.original.split()          # 仅空白切分
  改：ConceptSegmenter(set(TERMS.keys())).segment(expanded.original)   # 最长匹配切分
```

### 3.2 分层

```
services/
  query_expansion.py    # 水平/垂直扩展（未改）
 concept_segmenter.py   # 新增：中文概念切分（单一职责，可独立单测）
 query_translator.py    # 翻译：调用 ConceptSegmenter 切分，逐概念映射英文（改 1 行）
 query_builder.py       # 组装数据库 query（未改）
```

- **单一职责**：切分归 `ConceptSegmenter`、翻译归 `QueryTranslator`，切分逻辑可独立单测。
- **依赖注入**：`ConceptSegmenter` 的词典由调用方注入（`QueryTranslator` 传 `set(TERMS.keys())`），避免 `concept_segmenter.py` 与 `query_translator.py` 循环依赖。
- **零第三方依赖**：纯 Python 最长匹配，未引入 jieba 等分词库。
- **接口不变**：`_concepts_for` 仍返回 `list[list[str]]`，`translate()` / `translate_concepts()` 对外接口不变，`QueryBuilder` / `SearchService` 无需改动。

## 六、结论

1. **问题 1 已解决**：`太赫兹通感一体化` 正确切分为 `太赫兹` + `通感一体化`，并翻译为 IEEE Boolean。

3. **架构**：新增 `ConceptSegmenter`（纯逻辑、独立单测、零依赖），`QueryTranslator._concepts_for` 改一行调用，切分与翻译解耦。
