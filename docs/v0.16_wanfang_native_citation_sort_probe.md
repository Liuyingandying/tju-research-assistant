## 1. 结论：原生支持 ✅（普通检索 + 高级检索）

| 确认项 | 实测 |
| --- | --- |
| 排序入口 | 结果页排序栏：`span`「排序：」+ **`div.sort-item`「被引频次」**，父容器 `.sort-area`；同级还有其它 sort-item（下载频次等） |
| 点击后页面变化 | 普通页 URL 追加参数 **`&o={"field":"被引频次","order":1}`**（URL 编码）；高级页 SPA 内刷新（`advanced-search/paper?t=…`） |

| 授权依赖 | 被引值**匿名态即可见**（每卡 `.stat-item.quote` 正常显示）；排序不受 TJU 授权影响 |

## 2. 易混淆点（探针实测澄清）

- 结果卡片上另有一处 hover 统计弹层 `div.quote`（`.button-area` 内，文本「被引：3下载：29」）——**不是**排序入口，点击无排序效果（首轮探针误点验证）；
- 排序入口必须用 `.sort-area .sort-item`（文本含「被引」）定位。

## 3. Phase B 策略：**native**

Adapter 在 `ranking_mode == CITATION` 时二选一（实现取其一，探针证实等价）：
1. 结果页点击 `.sort-area .sort-item`（被引频次）；
2. 普通检索直接以 URL 参数 `o={"field":"被引频次","order":1}` 导航。

候选顺序即被引降序；`citation_count` 提取（Phase A3 卡片通道）在排序页同样可用。
