# v0.17 Phase 2.4-B-OFFLINE 报告：离线关键信息结构化整理最小闭环

日期：2026-09-07
范围：离线（无 LLM/无 API/无网络调用）结构化整理：StructuredSummary 模型 +
OfflineSummaryEngine（确定性子句抽取）+ GUI「关键信息整理」按钮与展示。
未实施：任何 API/provider、paper 详情摘要 resolver、新闻 NER、SummaryService 的
provider 分支（Phase 2.4-A 设计保留）。

## 1. 离线算法

确定性子句抽取（无生成、无补全）：

1. **证据收集**（EvidenceCollector，按 artifact 类型）：
   - news：`abstract`（列表摘要）+ `_news_content_head`（详情正文瞬态片段，
     搜索会话内存在）；
   - patent：`abstract`（列表 `.abstract-area`）；
   - paper：仅 `abstract`——**当前三源列表均不产出摘要 → 无 prose 证据**；
   - 标题不作为内容字段证据（仅凭标题不得推导技术结论）。
2. **分句/子句**：句末标点（。！？!?；;\n）分句；>50 字长句再按逗号切子句；
   去重；最短 3 字。
3. **字段评分**：字段词类命中计数（research_content=研究/针对/面向/开发/团队…
   core_technology=提出/采用/基于/系统/装置/模型… main_results=实现/结果表明/
   验证/研制… application_value=应用/临床/检测/成像/前景…）+ artifact 类型加成
   （patent：为了/实现/提供→研究内容、定量分析/定量检测→主要成果；
   news：入选/当选/突破/发表→主要成果）。
4. **选择**：每字段取最高分子句；**同一子句至多被一个字段使用**；
   平分按文档序（先到优先）。
5. **长度控制**：超 120 字截断加省略号（保持子串性质）。
6. **信息不足**：无 score>0 的未用子句 → 字段值 =
   “当前材料未提供足够信息，无法可靠提取。”，source_basis=none。

## 2. Evidence / no-hallucination 保证

输出四字段的每一项**必须是证据文本的子串**或固定"信息不足"文案
（测试 `test_no_hallucination_output_subset_of_evidence` 逐字段断言）；
source_basis 记录来源块标签（summary/abstract/detail_content/none）。
不出现证据中不存在的新技术名词。

## 3. StructuredSummary（models/summary.py）

四字段 str + source_basis dict；`to_dict/from_dict`；`items()` 按
研究内容/核心技术/主要成果/应用价值 固定顺序输出中文标签。无嵌套/confidence。

## 4. Cache

进程级 dict，key=(artifact_type, detail_url→doi→publication_number→归一化标题
兜底)；重复点击直接命中（`test_repeated_call_hits_cache` 验证修改原对象不影响
缓存返回）；上限 300。

## 5. UI

- 底部操作区新增**「关键信息整理」**按钮（"查看推荐理由"旁，document 图标）；
- 初始禁用；检索成功/demo 加载后启用；检索失败禁用；
- 未选中结果 → 提示"请先在表格中选择一条结果。"；
- 点击 → `summarize_offline`（纯文本计算，主线程执行，耗时毫秒级——
  审计结论：离线算法足够快，无需 Worker；future provider 化时再引入
  SummaryWorker，本阶段未锁死结构）；
- `SummaryDialog`：标题「自动关键信息整理」+ 四字段（研究内容/核心技术/
  主要成果/应用价值）+ 免责声明「以上内容由系统根据当前可获取的摘要、正文及
  元数据自动整理，请结合原始资料核对。」；措辞锁定无 "AI 整理结果"/"权威结论"。

## 11. 剩余限制

1. paper 证据为元数据级 → 全字段诚实"信息不足"（paper 摘要 resolver 待
   provider 授权阶段）；
2. 专利应用价值等深层语义需主权项/权利要求（未解析）；
3. news 详情正文仅搜索会话内瞬态存在（不入 to_dict，2.3-B 设计），GUI 复用
   列表摘要为证据——按需抓取留待 Phase 2.4-C；
4. 离线抽取为单句级相关性，非真正"理解"——演示口径：
   "自动整理 + 请结合原始资料核对"；
5. Edge fixture/门户偶发环境问题（既有类别）。
