# v0.16 CNKI「被引」列真机 DOM 探针报告（Phase A1）

> 日期：2026-09-06 ｜ 性质：只读探针，未修改生产代码
> 脚本：`poc_cnki_citation_dom.py` ｜ 产物：`runtime/cnki_citation_probe/`

## 1. 探针方法

复用生产会话与生产高级检索组件（真实授权链路，非手工 mock）：

- `BrowserSession.start()` → TJU 平台入口 → `open_cnki()`；
- **basic 路径**：CNKI 首页普通检索「太赫兹」→ `wait_for_result_page`；
- **advanced 路径**：`CNKIAdvancedQueryBuilder.build(page, "太赫兹", QueryRequest(author_affiliation="天津大学"))`
  → `wait_for_advanced_result_page`（即 v0.13 生产主路径）；
- 每条路径抓取 `table.result-table-list`：表头 th 全列、前 10 行逐 td（class/text/innerHTML/linkCount）、
  整表 HTML、整页截图；另做「点击被引表头排序→重读」实验与 15s 异步轮询等待。

## 2. 核心结论

### 2.1 「被引」列真实 selector：`td.quote`（非 `td.citation`）

| 项 | 实测 |
| --- | --- |
| 结果表 | `table.result-table-list`（两路径一致） |
| 表头列序 | （复选框）/ 题名 / 作者 / 来源 / 发表时间 / 数据库 / **被引** / 下载 / 操作 |
| 被引 th | 文本「被引」，class 为空 |
| 被引 td | **`class="quote"`**，两条路径 × 20 行全部一致 |
| 链接包裹 | 无（cell 内 0 个 `<a>`；值为纯文本数字形态） |

**现有生产代码 `cnki.py:_extract_citation_count` 使用的 `td.citation` 是错的**（离线 fixture 无被引列，
该 selector 从未被真实 DOM 校验）。Phase A2 将改为 `td.quote`。

### 2.2 空值形态与填充条件（本轮重要发现）

- 本轮探针运行时 TJU 门户会话已过期（`check_tju_auth → login_page`，探针按只读边界不自动登录），
  CNKI 处于匿名态：**结果页其余列全部健康（题名/作者/来源/发表时间 20 行有值），
  唯独「被引」「下载」两个统计列全空**（td 完全空文本，连占位符都没有）；
- 15s 异步轮询等待：未等到（`citation_async_wait_hit=false`）；
- 点击「被引」表头排序触发服务端重查：仍全空；
- 对照组：**昨日授权会话的真实截图**（`runtime/cnki_e2e/03_result_page.png`，同一高级检索路径），
  被引列 4/4 行有值：55 / 237 / 143 / 101（纯数字、无链接）。

**结论：被引统计列由 CNKI 授权态下发；匿名态下该列为空是"无数据"的真实形态。
生产环境用户经 GUI 授权流程登录后该列有值——填充率验收须在授权会话下复测。**

### 2.3 对解析实现的要求（Phase A2 依据）

| 输入形态 | 期望输出 |
| --- | --- |
| `td.quote` 文本 `"237"` | `237` |
| `td.quote` 文本 `"0"` | `0`（明确零引用） |
| `td.quote` 不存在 / 空文本 / `"--"` 等无数字文本 | `None`（未知） |
| 数字被链接包裹（容错） | 仍取数字（`re.search(r"(\d+)")` 天然兼容） |
