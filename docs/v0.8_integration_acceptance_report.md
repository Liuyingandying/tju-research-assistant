## 四、成功项

1. **完整闭环打通**：`中文关键词 → 概念切分 → 英文映射 → Boolean Query → IEEE 真实检索 → 元数据解析 → 报告生成` 六段链路在 3 个 Case 上全部端到端通过，报告为最终落盘产物。
2. **查询生成精确**：3 个 Case 的最终 query 与期望值逐字符一致，包括多词短语加引号（`"millimeter wave"`、`"integrated sensing and communication"`）与同义词 OR 组。
3. **切分与映射正确**：`毫米波`、`通感一体化` 均整词命中，未发生错误切分；全部概念命中领域词典。
4. **检索结果高度相关**：3 个 Case 各 10 条，前 3 篇均与输入方向强相关（太赫兹通信、毫米波通信、THz ISAC）。
5. **v0.8.2 元数据优化真实生效**：期刊项 venue/document_type 由 v0.8.1 的 `null` 补齐为 `China Communications` / `Magazine Article`；30 条结果中 29 条三字段齐全。
6. **报告生成闭环核验**：3 份 Markdown 报告均含检索条件、数据源统计、文献列表区块，前 3 篇的 title/year/venue/document_type 逐项在报告中可见（无 `—` 占位）。

## 五、剩余风险

1. **个别期刊项 document_type 仍缺失（低频）**：Case 2 第 10 条 `Symbol-Level Hybrid Precoding in mmWave Multiuser MISO Systems`（IEEE Communications Letters, 2019）year/venue 均有，仅 document_type 缺失（影响该 Case 全量完整率 90%）。推测该版式的类型标签文本不在当前 `_DOC_TYPE_RE` 词表内（如未知的标签变体）。可在后续版本探测该页 DOM 标签后补充词表；不影响检索与报告生成。
2. **IEEE 版式差异不可穷举**：结构化节点（`.description a` / `.publisher-info-container`）覆盖主流版式，但 IEEE 页面存在多种展示变体，个别字段仍可能为 null（正则回退可兜底 year，venue/type 无兜底时为 null）。
3. **词典覆盖有限**：TERMS 当前 11 个概念词。未命中词将原样透传（不猜测），如后续验收扩展到其他方向（如 `天线阵列`、`雷达感知`）需先校对 `antenna`/`radar` 等占位拼写（v0.8.1 已标注）。
4. **单页边界**：验收仅取第一页结果（10 条），未翻页、未进入详情页；`abstract/doi/keywords` 等详情字段不在本轮闭环范围内。
5. **授权与会话依赖**：验收依赖 TJU 授权会话有效（`runtime/edge_profile`）；会话失效时需人工在受控 Edge 中重新登录后方可复跑。
