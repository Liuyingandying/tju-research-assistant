## 3. 已知限制

- **作者名连写**：万方文本中作者名无分隔符，无法拆分为列表
- **DOI / abstract**：搜索结果页不提供，保持 None（需进入详情页，本阶段未做）
- **维普**：代理落地页空白（SPA 未渲染），暂缓接入
- **顺序多源检索**：非并行，多源时总耗时线性叠加
- **每任务独立会话**：Playwright sync API + QThread 限制，每次浏览器任务重启 Edge
  （授权由 Profile 保留，但窗口会闪现）
- **无持久化**：检索结果仅内存 + 用户导出文件，无历史记录/数据库
- **人工核对 PENDING**：程序输出与 CNKI 页面前 3 条的人工 cross-check 尚未由用户完成
- **演示数据 detail_url 为空**：演示模式下"打开全文页面"会提示无链接（有意为之，避免打开虚构页面）

## 4. 验收步骤

1. **环境检查**：运行 `python scripts/run_acceptance_check.py`，确认 5 项全部 ✅ PASS。
2. **授权检查**：启动 `python main.py` → 点击「检查授权状态」→ 应显示"天津大学授权正常"
   （若失效，先运行 `python poc_browser.py` 人工登录）。
3. **单源检索**：勾选 CNKI，输入"太赫兹"，点击「开始检索」→ 表格出现 10 条。
4. **多源检索**：勾选 CNKI + 万方 + IEEE Xplore，再次检索 → 结果合并、去重、排序，
   状态栏显示各源进度与总条数。
5. **打开全文页面**：选中一条结果 → 点击「打开全文页面」→ 受控 Edge 打开并保持。
6. **导出**：点击「导出结果」→ 选择 JSON/CSV/Markdown → 文件正常保存。
7. **报告生成**：点击「生成报告」→ 保存 .md → 打开确认包含检索条件/数据源统计/文献列表。
8. **演示模式**：断网或未授权状态下点击「加载演示数据」→ 表格出现 5 条（原始 6 条去重），
   报告与导出仍可正常演示。
9. **关于面板**：点击「关于」→ 显示 v0.7.0、三个数据源、六项功能、动态测试状态。
10. **人工 cross-check**（用户）：随机核对前 3 条结果与来源页面显示是否一致。
