## 1. source/database 最终语义（审计结论）

审计关键证据：`citation_selector.py:68` 按 **`result.database`** 分组，配额表按
source 名键控——若 database≠source 名，专利在 CITATION 模式会被并入万方论文组
或整体出局。

**最终决定：source 名 = database = `"万方专利"`**（registry 键与每条结果的身份一致）。

| 模块 | `"万方专利"` 下的行为 |
| --- | --- |
| SearchService quota | 独立来源配额（与论文源互不挤占） |
| citation_selector | 按 database 独立分组；citation 全 None → 组内综合分回退（既有语义） |
| RankingService | `DATABASE_WEIGHTS.get("万方专利")` → 0（无 DB 加分；未改 ranking，符合任务 §十一） |
| FilterService | `_is_wanfang`(=万方) 不命中 → 走 Phase 2.2-A 非 paper 语义（year→date、缺失保留） |
| UI | 数据库列显示「万方专利」+ 类型列显示「专利」标签（Phase 2.1 类型展示） |
| Merger | 类型感知去重（(patent, title) 键） |

## 2. Adapter 架构

`src/tju_info_retrieval/sources/wanfang_patent.py`（独立模块，与论文 wanfang.py 零耦合，未重构现 Adapter）：
- `WanfangPatentAdapter`：普通/高级双路径检索 + 列表页解析；
- `parse_patent_list_row(row)`：列表行 → 字段（纯函数，字符串容错）；
- `parse_patent_detail_fields(page)`：详情 og: meta → inventors/ipc/type/date（纯函数）；
- `WanfangPatentMetadataResolver`：bounded inventors/detail_url enrichment。

所有 selector/流程均来自 Phase 2.2-B 探针证据（模块 docstring 标注证据文件）。

## 3. 普通 / 高级检索路由

- **普通检索（topic only）**：landing `#search-input` 填原始中文词 → 检索 →
  /paper 结果页 → 点「专利」页签 → /patent?q=… 等待渲染。
- **高级检索（person 或 affiliation 任一出现）**：`/advanced-search/patent`：
  - person → 字段切「专利-发明/设计人」（模糊即可，无需论文作者的精确修正）；
  - affiliation → 字段切「专利-申请/专利权人」；
  - person 绝不作为普通关键词提交。

## 4. 五种查询组合（真机验证全部生效）

| 组合 | 行规划 | 真机结果 |
| --- | --- | --- |
| topic only | row0 主题（默认） | 太赫兹 → 5 条，5/5 发明人 |
| person only | row0→发明/设计人 | 殷贤华 → 5 条全含殷贤华 |
| topic + person | row0 主题 + row1→发明/设计人 | 双条件 AND（咖啡豆/滤波器/传感器） |
| topic + affiliation | row0 主题 + row1→申请/专利权人 | 太赫兹+天津大学 → 5 条全为天大 |
| person + affiliation | row0→发明/设计人 + row1→申请/专利权人 | 殷贤华+桂电 → 5 条全为桂电 |

空 topic + person：SearchService 已跳过 expansion 链（Phase 1 语义），专利适配器
仅从 query_context 读 author_name/affiliation。

## 5. Parser（列表页，全部执行器来自探针 04/12 json）

- title：`.title-area span.title`
- 法律状态：`.pre-publish` / `.sync-publish`（发明公开/发明授权）
- 专利类型/公开号：`span.t-ML6`
- 申请人：`span.authors`（专利行语义，不是发明人）
- 申请日/公开日：`span.applyDate`
- 摘要：`.abstract-area`
- 申请号/公开号/日期（编码）：`.title-id-hidden` ≡ `patent_ZL_申请号_公开号_YYYYMMDD`
- date 优先级：公开日 > 申请日 > id 编码日期

## 6. Resolver（inventors / detail_url）

`WanfangPatentMetadataResolver`：模式对齐 WanfangMetadataResolver
（缓存/单项超时/总预算/失败降级），专利字段独立。点击列表第 i 条标题 →
新标签 → 解析 `<meta property="og:article:author">`（逗号分隔结构化数据，
无需启发式拆分）→ 关闭。结果 `inventors` 拆分入 `artifact_metadata.inventors`，
`detail_url` 回填，authors 仅镜像。

## 7. Enrichment 上限（不随 CITATION 放大）

- `max_items = 8`（硬上限，不随 candidate_quota(≤50) 放大）；
- 单项 ≤5s、总预算 ≤30s；
- 详情失败/超时 → 跳过，不导致整次搜索失败；
- 未解析 inventors → 保持缺失/空，不伪造（FilterService unknown≠mismatch 保留）。

## 8. SearchResult 映射

```python
SearchResult(
    title=列表页标题, authors=[]（不镜像申请人！由 resolver 镜像 inventors）,
    year=公开日/申请日年份, source=申请人（展示语义, 非作者）,
    detail_url=resolver 回填（未解析为 None）, document_type=法律状态,
    database="万方专利", artifact_type="patent",
    artifact_metadata={"inventors": [...], "applicant": 申请人,
                       "publication_number": 公开号, "application_number": 申请号,
                       "date": 日期},
    citation_count=None,
)
```

## 9. Filter 集成（未改 filtering.py）

- inventors 匹配：`authors` + `artifact_metadata.inventors`（真机：殷贤华 命中）；
- applicant 匹配：`artifact_metadata.applicant`（真机：天津大学 命中）；
- year：`year` 字段 + `artifact_metadata.date`（测试 date="2023-05-01" 区间命中）；
- 缺失保留：unknown≠mismatch（测试锁定）。全部为 Phase 2.2-A 既有语义。

组内按综合分排序回退（citation_selector 既有逻辑），未改任何算法。

## 15. 剩余风险

1. **发明人 enrichment 依赖详情页打开**：上限 8 条/次，CITATION 模式候选扩大时
   非前 8 条专利无发明人（unknown 保留，展示列缺值）——演示可接受，
   Phase 2.2-D 可按需提高上限或缓存复用；
2. **`_row_by_field` 三级匹配依赖真机形态**：站点改版可能引入新存储形态，
   回读校验与 `未定位` 错误会先行暴露；
3. **og meta 是当前 inventor 唯一可靠来源**：若详情页移除该 meta，需回退
   文本启发式（当前无此计划）；
4. **万方门户授权过期**仍会中断真机链路（既有环境风险）；
5. citation 全 None：CITATION 模式专利组内综合分排序已覆盖，未实测巨大
   专利候选池场景。
