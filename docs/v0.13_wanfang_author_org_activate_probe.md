## 2. 实验2（隐藏元素机制）

- 结果页的 `quick-keyword-item`（题名/作者/**作者单位**/关键词/摘要）经计算样式检查为 `display/visibility` 隐藏模板（height=0），强制点击无效——**它属于结果页另一处“快捷检索词”UI，不是高级检索表单字段**；此前多轮在其上寻找“作者单位输入框”是方向性误判。
- 真正的“作者单位”输入在 `/advanced-search/paper` 表单中，**以“字段下拉选择”方式存在，默认选中“主题”**，需在下拉中选择——即“隐藏”的真相 = 表单默认字段不是作者单位 + 高级检索入口此前未打开。

## 3. 实验3（填写与提交）

- **字段选择与填写成功**：行1 字段下拉选中“作者单位”并填入 `天津大学`；行2 填入 `太赫兹`（v2/v3 均无填写异常）。

## 4. 必答四个问题

**Q1. 作者单位字段为什么隐藏？**
不是“隐藏”，而是两级事实：① 结果页的 `quick-keyword-item`“作者单位”标签属于另一快捷 UI（隐藏模板，不可激活，与表单无关）；② 官方高级检索表单的字段下拉**默认选中“主题”**，作者单位需下拉显式选择；③ 高级检索入口（结果页“高级检索”链接）在本环境下点击**偶发无导航**，导致此前始终未进入表单页。

**Q2. 如何激活？**
两步：① 进入官方高级检索页——点击结果页“高级检索”或**直连 `https://<智搜host>/advanced-search/paper`**（直连更可靠）；② 在行字段下拉（`.ivu-select` 行级）选择“**作者单位**”后输入单位名称。**游客态即可**（无需机构账号登录，表单可用）。

**Q3. 是否可以直接复用现有 WanfangAdapter？**
**基本可复用（表层面）**：高级检索表单的交互（字段下拉选择 + 输入框 fill + 提交）与 Adapter 现有 `#search-input` fill/click 技术同构；`query_context.author_affiliation` 已随 `adapter.search(..., query_context=query)` 传入（当前实现未读取）。接入只需：在 `WanfangAdapter.search` 内读取 `query_context.author_affiliation`，改用高级检索表单路径填充“作者单位”行，再触发提交——**无需改动 SearchService / FilterService / UI / 结果解析**。前提：解决 §4-Q4 的提交契约。

**Q4. 真实 search 请求字段是什么？**
**未捕获（证据缺口）**：提交控件未能触发（v2/v3 均零请求），故带“作者单位=天津大学”的 `/search` body 尚无样本。最可能的字段名仍为 **`OrganizationNorm`**（源自 facet 探针：/facet POST 字段号 9 的字符串值），但这是推断而非实证。
