## 三、评价

### 3.1 是否成功返回

**三个 Case 全部成功返回 5 条结果**，无空结果、无 `SearchError`、无语法错误。IEEE Xplore 对三种 query 格式（空格串 / 完整 Boolean / 简化 Boolean）均正常响应。

### 3.2 相关性

**三个 Case 相关性都很高**——前 5 条全部是"太赫兹（terahertz/THz）与通感一体化（ISAC / integrated sensing and communication）"交叉领域的英文文献，无一无关结果。

| Case | 相关性 | 说明 |
| --- | --- | --- |
| A（空格串） | 高 | 5 条全部相关；第 3 条标题含 "Terahertz Integrated Sensing and Communication" |
| B（Boolean） | 高 | 5 条全部相关；第 3/4 条更精确命中 "Integrated Sensing and Communication" 短语 |
| C（简化 Boolean） | 高 | 5 条全部相关；`"integrated sensing communication"`（去 "and"）仍命中 |

### 3.3 是否出现无关结果

**未出现无关结果。** 三个 Case 的前 5 条均为目标交叉领域文献。Case C 的第 4 条（Hybrid Channel Modeling ... Terahertz Monostatic Sensing）偏"太赫兹感知"，但仍在太赫兹领域内，属合理相关而非无关。

### 3.4 推荐 QueryBuilder 生成格式

**推荐 Case B（完整 Boolean Query）**：

```
(terahertz OR THz) AND ("integrated sensing and communication" OR ISAC)
```

理由：
1. **语义表达力最强**：同义词组内 OR（terahertz/THz）、组间 AND、多词概念用引号精确短语（`"integrated sensing and communication"`），与中文布尔串 `(A OR B) AND (C OR D)` 结构对齐；
2. **实测无空结果、相关性高**：Case B 返回 5 条全相关，且第 3/4 条精确命中完整短语，比 Case A 的空格串更能锁定"通感一体化"这一完整概念；
3. **引号短语有效**：`"integrated sensing and communication"` 被 IEEE 正确识别为短语，未拆词；
4. **语法正确**：括号平衡、引号成对，IEEE 引擎正常解析，无报错。

Case A（空格串）虽也成功且相关，但语义是隐式的（引擎猜测词间关系），无法表达"同义词 OR / 组间 AND"的层次，且 `integrated sensing and communication` 是裸词序列（可能被拆词）。Case C（去 "and" 的简化短语）也能命中，但语义不如 B 精确。

**结论**：QueryBuilder 对 IEEE 应生成 **Case B 格式**（布尔 + 引号短语）。

## 四、附注（解析观察，非 query 格式问题）

实测中所有结果的 `year` 字段为 `None`。原因：IEEE 结果页当前布局中，年份未以独立 `20\d{2}` 出现在 `item.innerText` 可被 `_YEAR_RE` 捕获的位置（venue 文本格式变化），属 `IeeeAdapter._parse_results` 的解析边界，**与 query 格式无关**。此观察供后续 IEEE 解析优化参考，不影响本次 QueryBuilder 语法验证结论。
