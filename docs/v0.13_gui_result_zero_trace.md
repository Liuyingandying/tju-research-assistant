## 3. 判定表（每个观测点的“0 意味着什么”）

| 观测点 | 若为 0 / 异常 | 含义 |

| A/B | author_affiliation='' 或 sources=[] | **UI 组装丢字段**（勾选状态/输入未读到）→ 定位在 UI 层 |

| F | < E 数量 | 合并去重误删 |
| G | < F | 过滤误删（核对模式与 metadata_map） |
| H | < G | worker→UI 信号层丢失 |
