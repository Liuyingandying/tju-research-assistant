## 2. 架构变化

### 2.1 新增模块

`services/query_builder.py`：

```python
BOOLEAN_SOURCES = {"IEEE Xplore"}
CHINESE_SOURCES = {"CNKI", "万方"}

class QueryBuilder:
    def build(self, source: str, translated_query) -> str:
        if source in BOOLEAN_SOURCES:
            return self._build_boolean(translated_query)   # 同义词 OR / 组间 AND / 多词引号
        if source in CHINESE_SOURCES:
            return self._build_chinese(translated_query)   # 透传中文原串
        return self._fallback(translated_query)            # 未知源空格连接（安全回退）
```

- **IEEE**：`(terahertz OR THz) AND ("integrated sensing and communication" OR ISAC)`——同义词组内 OR、组间 AND、多词短语加双引号。
- **CNKI/万方**：透传中文原串（`translated_query[0][0]`）。
- **未知源**：空格连接所有概念词（不报语法错误）。

### 2.2 QueryTranslator 演进

`QueryTranslator` 新增 `translate_concepts(expanded, sources) -> dict[str, list[list[str]]]`，返回**概念分组**：
- 英文源：`[[syn1, syn2], [syn3, syn4], ...]`（每个内层列表为一个概念的同义词组）；
- 中文源：`[[query_string]]`（透传原串）。

`translate()`（扁平串）保留，重构为基于 `_concepts_for` 内部实现，**对外行为与 Phase 1 完全一致**（现有 `test_query_translator.py` 断言不变）。

### 2.3 SearchService 调用链

```
SearchService.search()
  expanded = QueryExpansionService.expand(direction, expansion_direction)
  concepts = QueryTranslator.translate_concepts(expanded, sources)   # {源: 概念分组}
  for source in sources:
       query = QueryBuilder.build(source, concepts[source])          # 该库最终串
       adapter.search(query, count)
```

即：`QueryTranslator`（中文概念 → 英文概念） → `QueryBuilder`（概念 → 数据库专用 query） → `Adapter.search(query, count)`。

`adapter.search(keyword, count)` 接口签名不变，只是 `keyword` 变成该数据源对应语言的最终检索串。

## 4. 与 Phase 1 关系

| 维度 | Phase 1 | Phase 2 |
| --- | --- | --- |
| `QueryTranslator.translate()` | 输出扁平英文串 | 保留（向后兼容），重构为基于概念分组 |
| `QueryTranslator.translate_concepts()` | 无 | **新增**：输出概念分组 |
| `QueryBuilder` | 无 | **新增**：按数据源生成最终 query |
| IEEE query 格式 | 空格串 `terahertz THz ...` | Boolean `(terahertz OR THz) AND (...)` |
| CNKI/万方 | 透传中文串 | 透传中文串（不变） |
| SearchService 调用 | `translate → adapter.search` | `translate_concepts → build → adapter.search` |

Phase 2 在 Phase 1 基础上**新增** QueryBuilder 层，把"翻译"（概念）与"数据库语法适配"（query 组装）解耦；`translate()` 的扁平行为保留以兼容 Phase 1 测试。唯一行为变化是 IEEE 从空格串变为 Boolean（这是 Phase 2 的目标，且已被真实验证）。
