## 1. English OfflineSummary Changes

- **分句升级**（`split_into_clauses`）：句末标点类加入英文 `. ? !`；切分前先**保护
  科研文本常见 period**（e.g./i.e./et al./Fig./Eq./Dr./etc./vs./No./approx./cf.
  与小数 `0.5` 类数字间句点）→ 哨兵 → 切分 → 还原；中文 `.` 类行为不受影响。
- **英文词类最小集**（`EN_FIELD_LEXICONS`）：四字段各加 15-20 个英文词/phrase
  （research_content: study/investigate/aim/address/explore/analyze/this paper…；
  core_technology: propose/develop/based on/using/method/technique/device/model…；
  main_results: result/demonstrate/show/achieve/improve/outperform/validation…；
  application_value: application/can be used/potential/promising/enable/imaging/
  detection/biomedical…）。运行期与中文词类合并（英文词不会误命中中文，中文零回归）。
- 未新增 language/source 专用分支——同一套规则未来可服务任何英文 paper evidence。

## 2. Sentence Splitting

- 英文句号/分号/换行切分；
- 缩写保护：`e.g.` 不产生孤立 `g` 碎片；`i.e.`/`et al.`/`Fig.` 保持完整；
- 小数保护：`0.5 THz`、`1.75` 不被切成 `0`+`5 THz`；
- >50 字英文长句按逗号切 clause（复用既有机制）。
- 测试锁定：普通句号/分号/缩写/小数/连续空白/长句 clause。

## 3. Keyword Rules

英文词类仅作评分起点（§1）；算法保持 evidence → deterministic clause → field
scoring → evidence-substring 输出 → insufficient fallback。四字段英文抽取单元测试通过
（真实风格 IEEE fixture：research/core/main_results/application_value 均命中）。

## 4. No-hallucination

保持不变量：输出 = evidence 原文子串（允许 120 字截断 + “…” 后缀，仍为前缀子串）
或固定“信息不足”文案；**不做机器翻译**——中文字段标题下保留英文原句。

## 5. Selector Confirmation（实现前低频取证）

2 条真实 IEEE 论文（runtime/v0.17_paper_evidence_probe/08 json）：detail_url 列表直取、
direct URL ~22-24s 打开、无 consent、无机器人检测；Abstract 正文在页面文本
`Abstract: <content>`（内容接续在冒号后首行）；提取策略：`Abstract\s*:\s*...` 至首个
章节头（Index Terms/Keywords/Published in/© 等）截断，无标记时取首行 ≥10 字兜底。

## 6. IEEE Fetcher（sources/ieee_paper_evidence.py）

`IeeePaperEvidenceFetcher`（复用 cnki_paper_evidence 的 EvidenceError 体系）：
direct URL → 就绪轮询 → parse_ieee_abstract（章节头截断/首行兜底 + 空白归一）→
cache（URL 键，上限 300）。只取 Abstract；失败分类：no_url/timeout/auth/captcha
(bot 检测)/no_abstract/network。

## 7. Worker Reuse / Generalization

`PaperEvidenceWorker.fetch_abstract(source, detail_url)`：按 source 选择 fetcher
（CNKI→CnkiPaperEvidenceFetcher；IEEE Xplore→IeeePaperEvidenceFetcher），
同槽独立 BrowserSession 生命周期；未知 source → “当前来源暂不支持…”。
未新建第二个 evidence worker。

## 8. Routing（_on_summarize）

- paper + CNKI 无摘要 → CNKI fetcher；
- paper + IEEE Xplore 无摘要 → IEEE fetcher；
- paper + 万方 等无摘要 → 现有“信息不足”（不 fetch）；
- 已有 abstract 的任何源 → 直接 OfflineSummaryEngine（不重复 fetch）。

## 9. Timeout

各 fetcher 自带默认：CNKI 10s（不变）；IEEE 30s（PoC 实测单条 ~10-25s 经代理；
bounded 不无限等待）。真机实测 IEEE fetch 10.1s。

## 10. Cache

进程内 dict（key=detail_url）；真机二次调用 0.0s 同摘要，不重复开详情。

## Hotfix 记录（2026-09-08：英文 OfflineSummary 语义误分类）

**GUI 真实问题**：真实 IEEE 论文（Terahertz Tomography for Non-Destructive
Testing…）整理出现——研究内容=“and in this paper”（无意义 discourse 碎片）、
应用价值=“making it difficult to serve for the real life application”（负面
limitation 误作正向应用价值）、主要成果=“some efforts to improve…”（弱表达）。

**根因**：EN 词类把 "this paper"/"improve"/"application" 当充分信号——
discourse 碎片（and in this paper）仅凭该词即命中 research_content；
application 未区分正向/负向极性；main_results 未设强结果阈值。

**修复（只改 services/offline_summary.py）**：
1. `clause_eligible_for_field`（新增英文 gate，中文子句经 CJK 检测恒 True 零影响）：
   - discourse-only 碎片（and in this paper / however / in addition 等，
     全 token ⊆ discourse 集）→ 任何字段不入选；
   - research_content：需实质研究动作词（investigat/stud/address/focus/aim/
     explor/analyz/examin/evaluat）；
   - main_results：需强结果证据（demonstrat/achiev/result/validat/
     outperform/successfully/we found/show that/indicate…）——弱表达
     （efforts/attempt/仅 improve）不再够格；
   - application_value：含 negative/limitation 信号（difficult/limitation/
     cannot/however/suffers from…）→ 拒绝；
2. `_strip_leading_discourse`：选中英文子句剥离句首 discourse 前缀链
   （≤4 token，如 “and in this paper” → “a compressed sensing approach…”），
   余部仍为 evidence 子串（select 范畴，非改写）；中文子句原样返回；
3. **CJK 豁免**：含中文字符的子句跳过英文 gate（防“田震教授…Optica Fellow”
   这类内嵌英文词的中文句被误拦——探针 09 复现后修复）。

**No-hallucination 保持**：输出仍 = evidence 子串（strip/截断均为前缀性质）
或固定“信息不足”文案；未改写/翻译/补全。

**Tests**（+11，其中 2 条为既有断言按更严语义调整）：
- A “and in this paper” 不作 research_content；B 完整研究句保留；
- C 负面 limitation 拒作 application_value；D/E 正向应用句通过；
- F 弱 efforts 不作 main_results；G 强 experimental results 通过；
- H 英文输出仍为 evidence 子串；I 无候选全不足；J 中文零回归（含内嵌
  英文词句的 CJK 豁免）；discourse 通用拒绝；IEEE 路由扩展断言。

**真机复验**（同一 GUI 摘要）：研究内容=诚实不足（拒碎片）；核心技术=原文
“Terahertz tomography based on time-of-flight imaging is a promising…”；主要
成果=“a compressed sensing approach is demonstrated on measured data”（强结果
证据、discourse 前缀已剥离）；应用价值=诚实不足（拒负面 limitation）。
