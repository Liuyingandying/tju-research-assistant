# v0.4 PortalNavigator 设计与最小 PoC

## 设计目标

天津大学图书馆电子资源平台的**所有非 CNKI 资源**都通过统一门户
（`https://p.lib.tju.edu.cn/`）的"进入"按钮跳转，URL 包含随机代理子域
（不可硬编码）。`PortalNavigator` 封装该导航逻辑，使上层 `SourceAdapter`
无需关心门户交互、代理时序、502 重试等细节。

## 接口

```python
class PortalNavigator:
    """天津大学图书馆资源门户导航器。"""

    def __init__(self, session: BrowserSession) -> None: ...

    def open_portal(self) -> Page:
        """打开天津大学电子资源平台，返回门户页。"""

    def list_resources(self, category: str = "中文资源") -> list[str]:
        """列出指定分类下的资源名称（去重保序）。"""

    def open_resource(self, resource_name: str, category: str = "中文资源") -> Page:
        """打开指定资源，返回落地页 Page 对象。
        流程：点击分类 tab → 找资源卡片 → 点击“进入”
        → expect_page 等待代理隧道建立 → 处理 502 → 返回落地页。
        资源不存在时抛出 ValueError。
        """
```

## 使用流程

```python
from tju_info_retrieval.browser.session import BrowserSession
from tju_info_retrieval.browser.portal import PortalNavigator

session = BrowserSession()
session.start()
portal = PortalNavigator(session)
portal.open_portal()

# 列出资源
names = portal.list_resources("外文资源")
# 打开资源
landing = portal.open_resource("IEEE/IET Electronic Library", "外文资源")
# landing 是落地页，可在该会话中搜索
session.shutdown()
```

## 代理时序原理（关键技术发现）

TJU 代理"进入"按钮（`ng-click="hrefDetail(item)"`）触发 `window.open(proxy_url)`，
新标签页的打开需要**代理建立到目标站点的隧道**，耗时约 **10-30 秒**。

**Playwright sync API 的事件泵机制**：`time.sleep` 轮询 `context.pages` 无法捕获
新标签页的创建事件，必须使用 `context.expect_page()`（内部泵送事件循环）。
本次实现中，audit2/3/4 三轮验证了这一问题：
- audit2（`time.sleep` + `is not portal`）：系统性错位（点 X 落地 Y）
- audit3（轮询 `context.pages`）：全部超时（事件未泵送）
- audit4（`expect_page`）：全部正确

## 下一步（Adapter 接入）

1. 每个资源（万方 / IEEE）实现对应的 `SourceAdapter`，构造时接收 `PortalNavigator`，
   在 `search()` 中调用 `portal.open_resource(resource_name, category)` 获取落地页
   → 定位搜索框 → 输入关键词 → 检索 → 解析结果。
2. 搜索框 selector 已在审计报告中确认（万方 `#search-input`、IEEE `input[type=search]`），
   但**结果页 DOM 需先做专项审计**（每个资源一次真实搜索 + 解析结果表）。
3. 资源名包含订购后缀（如 `【TALIS订购】`），`PortalNavigator.open_resource`
   使用 `includes` 匹配，因此传"万方数据知识服务平台"即可匹配
   "万方数据知识服务平台"（无后缀）或"万方数据知识服务平台【TALIS订购】"（有后缀）。
