TJU Research Assistant（信息自动检索整理系统）v0.18 RC（Windows x64）

1. 支持 Windows 10/11 x64。请先解压全部文件，不要直接在 ZIP 内运行。
2. 双击“信息自动检索整理系统.exe”启动；无需安装 Python、pip、项目源码或开发工具，也不需要管理员权限。
3. 本系统需要电脑已安装 Microsoft Edge，不会自动下载浏览器。
4. 首次访问数据库时会打开独立的受控 Edge，请使用您自己的天津大学统一认证账号完成登录。首次访问可能需要稍等。
5. 本包不包含任何账号、密码、Cookie、Token 或开发者登录状态。登录状态只保存在本机当前 Windows 用户目录。
6. 登录失效时，请在受控 Edge 中重新完成天津大学登录；不要尝试绕过统一认证或验证码。
7. 日志目录：%LOCALAPPDATA%\TJU_Info_Retrieval\logs\
8. Windows SmartScreen 可能提示未知发布者：本包为未签名版本。本阶段不提供安装器或代码签名。

反馈问题时请提供：Windows 版本、程序版本、失败步骤、错误截图、上述目录中最新日志文件。
反馈界面显示问题时，请同时提供 Windows 分辨率和 Windows 显示缩放比例，例如：
1920×1080 / 125%、2560×1440 / 150%、1366×768 / 100%。
请勿提供：天津大学密码、Cookie、Token、Edge Profile 或其它登录数据。
