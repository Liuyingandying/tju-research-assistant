## 1. 项目定位

面向**正常授权用户**（天津大学师生）的科研信息检索辅助桌面应用：

- 在授权环境下，对多个学术数据库执行**正常、低频、用户主动发起**的单页检索
- 统一结构化、去重、排序后展示
- 支持打开全文页面、结果导出、Markdown 检索报告

**明确不是**：批量下载器、爬虫、授权绕过工具。全程无 AI（AI Mode 为后续规划）。

## 2. 技术架构

- **GUI**：PySide6（主线程渲染 + QThread 后台执行，QueuedConnection 跨线程）
- **浏览器**：Playwright sync API 驱动本机 Microsoft Edge（`chromium_sandbox=True`，
  专用持久 Profile `runtime/edge_profile`，不下载 Chromium）
- **数据源**：`AdapterRegistry` 注册 CNKI / 万方 / IEEE Xplore 三个 `SourceAdapter`
- **门户导航**：`PortalNavigator`（`context.expect_page()` 等待代理隧道建立，502 重载）
- **后处理**：`ResultMerger`（DOI→URL→标题三重去重）→ `RankingService`（标题匹配+年份+库权重）
- **词扩展**：`QueryExpansionService`（同义词词表 + 方向限定，纯规则，已真实验证 CNKI 布尔语法）
- **输出**：export（JSON/CSV/Markdown）+ report_generator（Markdown 检索报告）

## 5. 限制

- **作者名连写**：万方文本中作者名无分隔符，无法拆分为列表
- **DOI/abstract**：搜索结果页不提供（CNKI/万方），保持 None；未进入详情页获取
- **维普**：代理落地页空白（SPA 未渲染），暂缓接入
- **单会话顺序执行**：多源检索为顺序执行（非并行），多源时总耗时线性叠加
- **每任务独立会话**：Playwright sync API + QThread 限制，每次检索重启 Edge（授权由 Profile 保留）
- **无持久化**：检索结果仅内存 + 用户导出文件，无历史记录/数据库
- **人工核对**：程序输出与 CNKI 页面前 3 条的人工 cross-check 仍标记 PENDING

3. 人工 cross-check 完成 → 合并 `poc1-cnki-metadata` 分支
4. 可选增强：检索历史（本地文件）、WOS 接入、并行多源检索（独立 session）
