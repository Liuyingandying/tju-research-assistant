## 1. Secret Backend

新优先级（Windows，正式生产路径禁止明文）：

```
1. keyring / Windows Credential Manager（service=TJU_Info_Retrieval_AI）
2. Windows DPAPI 加密文件 %LOCALAPPDATA%\TJU_Info_Retrieval\config\credential.dat
   （win32crypt 优先、ctypes 兜底，均无新依赖；DPAPI 密钥由当前 Windows

```
