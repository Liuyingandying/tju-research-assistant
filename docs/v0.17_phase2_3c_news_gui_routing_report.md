## 1. UI

成果类型行扩展（现代蓝白风格，无新 Tab/页面）：

```
成果类型： ☑ 论文  ☐ 专利  ☐ 新闻   [新闻来源：天津大学新闻网]
```

- 默认：论文 checked、专利/新闻 unchecked —— 旧用户行为完全一致；
- 「新闻来源：天津大学新闻网」只读提示仅勾选新闻时显示（isHidden 切换）；
- 未在数据库区新增第四个复选框（source ≠ artifact_type）。

## 2. 新闻来源展示语义

- 数据库列：`天津大学新闻网`（内部 source/database 身份）；
- 来源列：**真实媒体**（健康报 / 科技日报 / 精仪学院 / 党委宣传部…，来自
  `artifact_metadata.media` = `SearchResult.source`）；
- 类型列：`新闻`（Phase 2.1 标签）；
- 作者列：仅详情真实署名（resolver 镜像），媒体名绝不入作者列；
- 文档统一描述：**以天津大学新闻网为新闻检索入口，覆盖天津大学科研新闻及
  站内转载的部分中央媒体报道**。

## 3. artifact routing

`services/artifact_routing.py`：新增 `ARTIFACT_NEWS → NEWS_INTERNAL_SOURCE
("天津大学新闻网")`，**不依赖任何数据库复选框**（勾选即可执行）；语言适用性
（英文模式不可用）由 GUI 层在调用前过滤 selected_artifact_types，resolver
保持纯映射。None/[] 语义（Phase 2.2-D Hotfix）不变。

## 5. 默认兼容

默认（论文 ✓ / 专利 ✗ / 新闻 ✗）→ request.sources 与改动前逐项一致；
既有 GUI/语言/strict 测试全部回归通过。

## 6. partial support warning（非阻断状态提示，不阻止其它有效成果）

- 专利+新闻 + CNKI → sources=[天津大学新闻网]，状态栏
  「当前所选来源不支持专利检索，本次将仅检索新闻。」；
- 论文+新闻 + 数据库全不勾 → 状态栏「未选择可用的论文数据源，本次将仅检索新闻。」
  并继续新闻检索。

## 7. language

- 中文 / 中英双语 → news 可执行（测试锁定）；
- 仅新闻 + 英文 → 阻止「天津大学新闻网当前仅支持中文新闻检索，请切换为中文
  或中英双语。」；
- 论文+新闻 + 英文 + IEEE → IEEE 可执行 + 状态栏「当前语言模式不支持中文新闻，
  本次将不检索新闻。」；
- 英文模式未删除，判定基于最终 effective sources。

## 8. strict

- 仅新闻 + IEEE 复选框 + strict → effective=[天津大学新闻网] → **不误杀**；
- 论文+新闻 + IEEE + strict → effective 含 IEEE Xplore → **仍阻止**；
- 全部基于 resolve 后 effective sources（测试锁定）。

## 9. affiliation + strict（不修改 FilterService）

- 全新闻来源 + 人员单位 + strict → FilterService 必然删除全部新闻（Phase 2.2-A
  语义）→ GUI 提交前阻止：「新闻结果暂无人员单位元数据，严格单位匹配将无法
  保留新闻结果。请切换为智能匹配或清空人员单位。」；
- 混合来源（含论文/专利）+ 单位 + strict → 非阻断提示「严格单位匹配可能排除
  新闻结果。」，不擅自更改 strict 设置；
- 新闻 + 单位 + soft → 正常执行。

## 10. 联合检索

quota 仍用现有 source-level 均分（artifact-level 配比留作后续优化）。

B. 仅新闻 + 数据库全不勾 + 方向「太赫兹」→ 返回真实新闻（类型列=新闻，
   来源列=健康报/科技日报等真实媒体，数据库列=天津大学新闻网）；

E. 专利+新闻 + 万方 → 同列表出现专利与新闻；
F. 三类型全勾 + 万方 → 论文/专利/新闻同列表；

H. 仅新闻 + IEEE 复选框 + strict → 不被误杀；
I. 三类型全不勾 → 仍阻止「请至少选择一种成果类型。」；
J. 仅新闻 + 单位 + strict → 提交前阻止（新闻无单位元数据提示）。

## 16. 剩余风险

1. 三类型全勾时 quota 均分（如 20 → 5/5/5/5/5）使单来源结果变少——课程演示
   可接受，artifact-level 配比留作可选优化；
2. 专利/新闻 enrichment cap（8 条）在联合大候选池下非前 8 条元数据缺失
   （unknown 保留语义兜底）；
3. 新闻英文模式提示为「本次将不检索新闻」（任务示例为「仅检索英文文献」，
   语义一致、覆盖专利/新闻混合场景更准确）；
4. Edge fixture 偶发启动争用（38 errors 模式）——环境性，重跑即恢复；
5. 新闻搜索范围限于天大新闻网（含转载）——PoC 已记录的来源边界。
