- 即“v0.7.1 发布提交”内承载的对外版本号仍是 0.7.0。
- `docs/v0.7.1_authorization_fix.md`（第 5 节限制 6）已明示此为**有意保持**：
  不升版本，以免破坏验收脚本断言；本次只做功能修复不进版本号。

**处理结果（用户已确认）**：选择“升版本并同步后再提交”——

测试数 210）、`scripts/run_acceptance_check.py`（`check_version_info` 断言与报告标题）、
`tests/test_acceptance_check.py`、`docs/v0.7.1_authorization_fix.md`（限制项 6）。
