## 1. Packaging audit

正式入口为 `main.py`。审计覆盖了绝对路径、当前目录依赖、`runtime/edge_profile`、资源加载、Edge 查找、Playwright driver 以及 PySide6 Qt plugins。

发现并处理的打包风险：

1. `poc_browser.py` 的 profile 固定在仓库 `runtime/edge_profile`；冻结态现改由统一 path helper 解析到用户目录，开发态语义保持不变。
2. `LibraryStore` 的默认 `data/library.json`、demo 数据和天津大学 logo 存在 cwd/source-tree 依赖；已分别切换为用户数据路径或 bundle resource 路径。
3. Edge 查找原先只覆盖两个固定 Program Files 路径；现在覆盖 `Program Files`、`Program Files (x86)`、`LocalAppData`，仍只调用系统 Edge。
4. Playwright 需要其 Node driver/package data；使用专用 hook 收集官方运行资源，同时排除不参与运行的 CLI skills 文档。
5. PySide6 需要 `qwindows.dll` 等 Qt plugin。PyInstaller 官方 hook 已收集这些依赖，没有全量收集所有 Qt 模块。
6. 构建环境 PATH 中的 Poppler ICU 78 会被误收进包并导致 `PySide6.QtGui` 加载失败。spec 明确排除该外部 `icuuc.dll`/`icudt78.dll` 后，冻结 GUI 正常启动。

未修改 Query、Expansion、各来源 adapter、Evidence、Ranking、Filter 或 GUI 功能设计。
