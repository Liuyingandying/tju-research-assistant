# v0.3 Query Expansion 功能设计

## 1. 背景与目标

当前 MVP（v0.2-functional）中：
- `QueryRequest.expansion_direction`（综合/理论/应用/综述）**只入模型、不参与检索**。
- `SearchService.search` 直接用 `query.research_direction` 作为 CNKI 检索词。
- GUI 的"扩展方向"下拉框存在但 tooltip 标注"后续阶段开放"。

v0.3 目标：让"扩展方向"真正影响检索——在**一次正常、低频、用户主动发起的单次检索**内，
把研究方向扩展为一条更完整的检索表达式，扩大召回又不失方向。

约束：
- 不引入 AI / LLM（纯规则、确定性、本地）。
- 不引入新依赖。
- 不增加搜索次数（仍是**单条 CNKI 检索**）。
- 不改变授权/批量/翻页/下载等安全边界。
- 扩展过程对用户**透明**（状态栏展示最终检索串，避免误导）。

## 2. 核心设计：QueryExpansionService

新增纯逻辑服务（无浏览器/网络依赖，便于单测）：

```
src/tju_info_retrieval/services/query_expansion.py
├─ ExpandedQuery            # 扩展结果数据类
└─ QueryExpansionService    # 扩展服务
    ├─ SYNONYM_THESAURUS    # 内置同义词词表（有限、人工维护）
    └─ DIRECTION_FILTERS    # 扩展方向 → 附加限定词
```

### 2.1 ExpandedQuery（扩展结果模型）

```python
@dataclass
class ExpandedQuery:
    original: str            # 原始研究方向
    expansion_direction: str # 综合 / 理论 / 应用 / 综述
    terms: list[str]         # 水平扩展后的检索词（含同义词）
    filters: list[str]       # 方向附加限定词（综合为空）
    query_string: str        # 最终单条 CNKI 检索串
    notes: list[str]         # 人类可读说明（哪些词来自词表/默认）
```

### 2.2 扩展策略（两级，均为规则）

**A. 水平扩展（同义词）** —— 有限内置词表，未命中则用原词，绝不猜测：

```python
SYNONYM_THESAURUS = {
    "太赫兹":   ["THz", "太赫兹波", "Terahertz"],
    "深度学习": ["深度神经网络", "DNN", "神经网络"],
    "机器学习": ["机器学习", "Machine Learning", "ML"],
    "知识图谱": ["Knowledge Graph", "知识图"],
    # 可按需人工扩充
}
```

**B. 垂直扩展（方向限定）** —— 把扩展方向映射到附加限定词：

```python
DIRECTION_FILTERS = {
    "综合": [],                                   # 不加限定
    "理论": ["理论", "机理", "原理", "模型", "算法"],
    "应用": ["应用", "系统", "装置", "实现", "工程"],
    "综述": ["综述", "进展", "研究现状", "展望", "回顾"],
}
```

**C. 组装单条布尔检索串**（CNKI 基础检索框支持 `OR / AND / 括号`，需真实验证）：

```
terms 部分：  (太赫兹 OR THz OR 太赫兹波)         # 仅一个词时直接用该词
filters 部分：(理论 OR 机理 OR 原理)              # 综合时省略
最终：       (太赫兹 OR THz OR 太赫兹波) AND (理论 OR 机理 OR 原理)
```

### 2.3 边界与回退

- 研究方向为空 → 沿用现有 `QueryRequest.validate()` 抛 `ValueError`。
- 词表未命中 → `terms = [原始词]`，不伪造同义词。
- 综合方向 → 无 filter，仅返回同义词扩展后的词。
- 若真实 CNKI 页面验证发现基础框不支持布尔语法 → **回退为原始词直接检索**（扩展降级为空操作），并保留状态栏提示"CNKI 未支持布尔扩展，已按原词检索"。

## 3. 数据流（改造后）

```
MainWindow._on_search
  → QueryRequest(research_direction, expansion_direction, databases, result_count)
  → worker.search(query)                       [QThread]
  → SearchService.search(query, status=...)    [新增步骤]
      ├─ emit("正在检查天津大学授权...")
      ├─ check_tju_auth()                       # 授权 gate（不变）
      ├─ session.open_cnki()                    # 打开 CNKI（不变）
      ├─ expanded = QueryExpansionService().expand(query)   # ★新增
      ├─ emit(f"已扩展：{expanded.query_string}")
      ├─ adapter.search(expanded.query_string, count)        # 检索串替换原词
      └─ emit("正在解析结果...")
  → search_done(results)                       [主线程填充表格]
```

关键点：**扩展发生在 SearchService 内**，把 `research_direction` 替换为 `expanded.query_string`
传入 `CNKIAdapter.search`。`CNKIAdapter` 与 `BrowserSession` 完全不动。

## 4. GUI 交互方式（最小）

现状：`combo_expansion`（综合/理论/应用/综述）下拉框已存在且可用。

改动：
1. 更新 tooltip："扩展方向：理论/应用/综述会附加对应限定词（综合=不附加）"。
2. 检索过程中状态栏展示扩展后的检索串（用户可看到实际执行了什么，透明不误导）。
3. 检索完成后状态栏保留"检索完成：N 条"；扩展信息在状态栏滚动显示即可，**不加新控件**。

GUI 不感知扩展内部逻辑——它只负责把 `expansion_direction` 放进 `QueryRequest`（已如此）。

## 6. 测试计划

`tests/test_query_expansion.py`（纯逻辑，无浏览器）：
1. 同义词命中：`太赫兹` → `terms` 含 THz / 太赫兹波。
2. 词表未命中：原词保留，`terms == [原词]`，无伪造。
3. 方向映射：理论/应用/综述 → 正确 filters；综合 → 空 filters。
4. 检索串组装：`(太赫兹 OR THz) AND (理论 OR 机理)` 形态正确；综合时无 AND 部分。
5. 空方向 → 抛 `ValueError`。
6. 回退逻辑：布尔串仅在词表/方向产生实际附加时才构造。

## 7. 验证与风险

**首要风险（必须先真实验证）**：CNKI 基础检索框是否解析 `(A OR B) AND (C OR D)` 布尔语法。
v0.3 dogfood 第一步：用扩展后的检索串在真实页面检索一次"太赫兹"，观察结果数是否合理、
是否按布尔解析。若失败 → 启用 §2.3 回退（原词检索），扩展功能标记"实验性"。

其他风险：
- 词表有限：未命中即原词，不影响现有功能。
- 附加限定词可能过严/过宽：状态栏展示实际检索串，用户可自行判断并调整方向。

## 8. 数据流图

```
用户选择: 研究方向="太赫兹"  扩展方向="理论"
         │
         ▼
QueryRequest(research_direction="太赫兹", expansion_direction="理论")
         │
         ▼
QueryExpansionService.expand()
   ├─ 同义词: ["太赫兹","THz","太赫兹波"]
   ├─ filters: ["理论","机理","原理","模型","算法"]
   └─ query_string: (太赫兹 OR THz OR 太赫兹波) AND (理论 OR 机理 OR 原理)
         │
         ▼
CNKIAdapter.search(query_string, count)   ← 单次检索
         │
         ▼
search_done → GUI 表格 10/20 条
```
