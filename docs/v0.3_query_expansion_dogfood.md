# v0.3 Query Expansion 真实 CNKI dogfood 报告

日期：2026-09-01
环境：真实天津大学授权会话（`runtime/edge_profile`），当前 `SearchService + CNKIAdapter`，未修改任何代码。
方法：同一受控 Edge 会话顺序执行 3 个 case（间隔 6 秒，低频、用户主动触发的单次检索）。

## 总结论

**CNKI 基础检索框真实解析布尔语法 `(A OR B) AND (C OR D)`** —— 设计文档标记的
首要风险已通过真实验证排除。三个 case 全部成功返回结果，无异常、无验证码/风控。
Query Expansion 可以安全接入 GUI。

## Case 1：太赫兹 + 综合

- **实际检索串**：`(太赫兹 OR THz OR 太赫兹波 OR Terahertz)`
- **成功返回**：是
- **返回数量**：10
- **前 3 条标题**：
  1. 太赫兹技术在癌症诊断医学中的应用
  2. 空气等离子体的太赫兹波调控技术综述（特邀）
  3. 太赫兹波在磁化等离子体中的3维传播与衰减特性
- **异常**：无
- 观察：同义词 OR 扩展生效（第 2 条即"太赫兹波"同义词命中）。

  3. 基于生物检测的太赫兹超材料的研究
- **异常**：无
- 观察：AND 方向限定生效，结果明显偏向建模/机理/分析类。
