# v0.16 IEEE Xplore 原生「按被引排序」能力探针报告（Phase B0）

> 日期：2026-09-06 ｜ 只读探针：`poc_ieee_native_sort_probe.py`
> 产物：`runtime/ieee_native_sort_probe/`（JSON + 前后截图）
> 边界：未使用 REST API（任务禁止）；直连原始站 `ieeexplore.ieee.org`

## 1. 结论：原生支持 ✅（官方排序选项 "Most Cited By Papers"）

| 确认项 | 实测 |
| --- | --- |
| 排序控件 | 结果工具栏 `div[ngbdropdown]`（"Sort By"），toggle 为 `button[ngbdropdowntoggle]`（默认显示 "Relevance"）；菜单 `div[ngbdropdownmenu]` |
| 官方排序选项 | **Relevance / Newest / Oldest / Most Cited By Papers / Most Cited By Patents / Most Popular**（`button.dropdown-item.filter-popover-option`） |
| 选择方式 | 点击 toggle 展开菜单 → 点击 "Most Cited By Papers"；Angular 弹层受视口/遮挡影响，Playwright 定位点击易超时，**JS click 稳定**（探针最终方案） |
| 降序验证 | "terahertz communication" 选择 Most Cited By Papers 后前 10 条：**4611 → 2426 → 2406 → 2092 → 1749 → 1636 → 1515 → 1453 → 1421 → 1319**（item 内可见 `Cited by: Papers (N)`），严格降序；对照 Relevance 序（1/9/2/3/9/…/673 无序） |
| TJU 授权代理环境 | 搜索与排序**匿名直连即可用**（v0.9.2 结论：原始站不经代理隧道，WAF 正常）；代理会话内页面结构一致（`ieee_dom_probe2` 同为 `.List-results-items .result-item`） |

## 2. 备选与注意

- 备选方案（未采用）：扩大候选池 + 本地 `citation_count` 排序——IEEE 搜索页每条已带 `Cited by` 值（Phase A4 已提取），即便原生排序失败也可本地兜底；
- class 名含 Angular 生成成分，Adapter 实现优先用结构属性（`button[ngbdropdowntoggle]`、文本精确匹配 "Most Cited By Papers"），失败静默跳过（保持相关性序候选，不影响返回）。

## 3. Phase B 策略：**native**

Adapter 在 `ranking_mode == CITATION` 时：搜索 → JS 展开 Sort By → 选 "Most Cited By Papers" → 等待重渲染 → 抓候选。无 REST API、无新依赖。
