## 二、词典结构

### 2.1 `terminology.py` 结构（与原有 `TERMS` 一致）

```python
TERMS: dict[str, dict[str, list[str]]] = {
    "太赫兹":   {"en": ["terahertz", "THz"]},
    "通感一体化": {"en": ["integrated sensing and communication", "ISAC"]},
    "通信":     {"en": ["communication"]},
    "无线通信":  {"en": ["wireless communication", "wireless"]},
    "毫米波":    {"en": ["millimeter wave", "mmWave"]},
    "6G":       {"en": ["6G", "sixth generation"]},
    "感知":     {"en": ["sensing"]},
    "雷达":     {"en": ["radar"]},

    "天线":     {"en": ["antenna"]},

```

- **结构不变**：`dict[str, dict[str, list[str]]]`，外层 key 为中文概念，内层 `"en"` 为英文等价词列表。下游（`ConceptSegmenter`/`QueryTranslator`/`QueryBuilder`）无需改动。
- **第一批 11 词**：`太赫兹`、`通感一体化`、`通信`、`无线通信`、`毫米波`、`6G`、`感知`、`雷达`、`阵列`、`天线`、`波束形成`。

### 2.2 `validate()` 校验

```python
def validate(terms=None) -> list[str]:
    """校验词典，返回问题列表（空列表表示通过）。"""
```

检查项：中文 key 非空、每个概念 `en` 列表非空、无重复 key（防静默覆盖）。供测试与加载时调用。

### 2.3 依赖方向

```
terminology.py  (纯数据 + validate)
      ↑
query_translator.py  (import TERMS)
      ↑
ConceptSegmenter / QueryBuilder / SearchService   (均未改)
```

`ConceptSegmenter` 仍经 `set(TERMS.keys())` 取 key 做最长匹配（逻辑未动）。`QueryTranslator` 用 `TERMS.get(piece, {}).get("en")` 翻译。
