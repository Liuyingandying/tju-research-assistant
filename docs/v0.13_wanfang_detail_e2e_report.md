## 2. 重点验证项

### 2.1 storage_state 授权是否有效 —— ✅ 有效
- Resolver 会话（DetailBrowserSession，storage_state 注入，非持久 Profile）成功通过门户 SSO → 代理隧道 → 万方检索 → 详情访问全链路；
- 详情页右上角身份显示"天津大学"，代理 URL（`wzxepffr…-s.p.lib.tju.edu.cn/periodical/<id>`）直接可访问；
- 授权来源链：检索成功时任务会话 `export_storage_state()` → 详情会话注入 → 门户免登录。

### 2.2 新标签 adopt 是否正确 —— ✅ 正确
- 每次解析后详情 Edge 均为 3 标签结构：门户（图书馆电子资源远程访问云系统）/ 万方落地页 / **adopt 的详情页（活动标签）**，与设计一致；
- 两篇论文窗口标题分别正确（"主动式太赫兹成像在枪支检测中应用现状-期刊-万方…"、"太赫兹成像技术的无损检测应用-期刊-万方…"），详情页正文（DOI/作者/单位/摘要）与所选行一致；
- 探活跟随 adopted 页面：关闭窗口后 worker 正常结束（第二次打开无任何跨会话干扰）。

### 2.3 关闭后第二次打开是否正常 —— ✅ 正常（含一次偶发失败的处理）
- 第一次关闭后，第二篇解析成功；失败重试亦成功；同篇重复解析（第三次）同样成功 → resolver 可重复使用，无状态残留。

### 2.4 CNKI / IEEE 是否受影响 —— ✅ CNKI 已实测无影响
- CNKI 行详情走 `open_detail_requested` 原 url 模式：单标签直开知网详情页，~15s，无门户/万方标签、无 resolver 调用（键控分支生效）；
- IEEE 未单独实测（同一 url 模式代码路径，风险与 CNKI 相同，单元测试覆盖 `test_url_mode_does_not_call_resolver`）。

## 4. 异常与风控观察

- **1 次渲染超时失败**："万方结果页未在时限内渲染"（25s）。失败路径行为完全符合设计：错误信息明确显示在状态栏、无窗口打开、Edge 进程被立即回收（进程表无孤儿）、应用可继续操作、重试成功。→ 判定为代理/站点偶发慢渲染，非结构性缺陷。
- **建议**（记录，不在本次范围）：`_wait_results_stable` 超时 25s → 放宽至 45s，可消除该类偶发失败（参数位于 `wanfang_resolver.py` 顶部）。
- **无验证码、无代理 502、无反爬拦截**贯穿全程（含 4 次万方解析 + 1 次检索 + 1 次失败重试）。
