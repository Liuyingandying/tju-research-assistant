## 3. 页面结构发现

### 3.1 结果页（对 detail_url 回填的影响）

- 结果条目标题为 Vue 组件：`div.title-area` 内 `<span class="title">基于<span class="highlight">太赫兹成像</span>技术的GFRP复合材料缺陷检测研究</span>`；
- **整页不存在结果标题的 `<a href>`**（`title_area.html` 留档：无 href、无 data-id、无任何论文标识属性）；
- 结论：`WanfangAdapter._extract_title_links` 在真实结果页将匹配 0 条链接，`detail_url` 回填实际返回 None（合成 DOM 单测仍有效，真实页面无锚点可提取）；
- 正文正则（`_RESULT_RE`）在真实结果页命中 20 条——结果条目解析路径有效。

### 3.2 详情页（代理 URL，新标签直接打开可正常渲染，fetcher 真实形态已验证）

页面标题：`基于太赫兹成像技术的GFRP复合材料缺陷检测研究-期刊-万方数据知识服务平台`

| 区域 | 候选 selector | 实测文本样例 |
|---|---|---|
| 作者区（含单位角标） | `div.author.detailTitle` | `张元 1 周文慧 2 葛宏义 2 蒋玉英 3 …` |
| 单作者链接 | `a.test-detail-author` | `张元 1` / `周文慧 2` |
| **作者单位区（编号分组）** | `div.organization.detailOrganization` | `1.河南工业大学粮食信息处理与控制教育部重点实验室,河南郑州 450001;河南工业大学河南省粮食光电探测与控制重点实验室,…4500012.河南工业大学…`（组间以 `N.` 编号、组内以 `;` 分隔，存在 `4500012.` 粘连） |
| **单位链接（每组一条）** | `a.test-detail-org` ★推荐 | `河南工业大学粮食信息处理与控制教育部重点实验室,河南郑州 450001;…` |
| 相关机构（推荐位，**非**作者单位） | `span.organizationname` | `兰州交通大学` 等（勿混用） |
| 区块标题 | `p.informationTitle` | `相关机构` |

- 页面无 JSON-LD / `__NUXT__` / `__INITIAL_STATE__` 可用结构化数据（`embedded_json: 0`）——DOM 解析是唯一路径；
- 干扰节点：`anxs-8qwe-*`（机构绑定推广弹层）、`organizationname`（相关机构推荐），解析时需排除。

## 4. 最终推荐解析路径

**Fetcher 形态：授权会话内新标签直接打开 detail_url（代理 URL），等待渲染后取：**

1. `a.test-detail-org`（`all_inner_texts()`）→ 每条按 `;` / `；` 拆分 → 逐条 strip → 单位列表（首选，天然按编号分组且免去 `4500012.` 粘连问题）；
2. 兜底：`div.organization.detailOrganization` 的 innerText，按 `(?<![0-9])\d+\.` 编号切分后再按 `;` 拆分；
3. 作者名（如需）：`a.test-detail-author`。

推荐 selector 优先级：`a.test-detail-org` > `div.organization` > `p.informationTitle` 邻近文本（仅作诊断）。

## 5. 失败备用方案（实测数据）

| 备用方案 | 实测结果 |
|---|---|
| 原始站直连（`d.wanfangdata.com.cn`，无头/无会话） | **失败**：页面 24 秒内 body 恒 467 字符，SPA 壳不水合，`a.test-detail-org` 始终 0 个（疑似反爬/环境校验）。若未来启用需仿 IEEE `_settle` 轮询且成功率存疑 |
| 从代理 URL 提取原始 URL | **不可行**：域名重写代理不内嵌原始域名，令牌无法离线解码 |
| 结果页 `<a>` 锚点提取 detail_url | **真实页面无锚点**（SPA 点击路由），仅合成 DOM 有效 |

**架构性约束（实施 fetcher 前必须解决）**：真实结果页拿不到 per-result detail_url（无锚点、无 ID 属性），`fetch_affiliations(detail_url)` 的输入来源缺失。可选出路：
1. 检索阶段点击捕获（每条结果一次点击/新标签，重量级、易触发风控）；
2. fetcher 内按标题在万方详情站二次检索定位（每结果一次额外导航）；
3. 万方暂不接入单位筛选（strict 下按"无数据删除"语义运行，UI 提示明确化）。

建议按 3 → 2 的顺序评估成本后再实施。
