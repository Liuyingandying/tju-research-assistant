## 1. SearchResult 模型字段（models/result.py）

| 字段 | 类型 | 万方现状 |
|-|-|-|
| rank | int | 文档序 |
| title | str | ✅ DOM `.title-area span.title` |
| authors | list[str] | ❌ 常为空 |
| source | str | ❌ 常为空 |
| **year** | str | ❌ **经常为空**（时间过滤 0 条根因） |
| detail_url | str | ❌ 恒 None（真实结果页无 `<a href>`） |
| document_type | str | ⚠️ 部分有 |
| database | str | ✅ “万方” |
| doi | str | ❌ 无来源 |
| **citation_count** | int/None | ❌ 无来源（**模型字段已存在**，v0.11 引入） |
| abstract/keywords/venue/authors_raw | — | ❌ 无来源 |

结论：**补全不需要改模型**——所有目标字段（year/authors/citation_count/detail_url/doi）均已在 SearchResult 中定义，缺的是填充来源。

## 2. 当前 WanfangAdapter 输出结构（`_parse_results` 现状）

```
_parse_results(page, count):
  ① DOM 通道：.title-area span.title → dom_titles（真实标题，按文档序）
  ② 正则通道：_RESULT_RE 解析 body 文本 → regex_rows
     （title/authors_raw/source/year/citation_count，pattern 要求
       “数字. 标题 | [类型]作者-《来源》YYYY” 形态）
  ③ 合成：dom_titles 逐条与 regex_rows 归一化标题匹配
     → 匹配成功：补充 authors/source/year/citation_count
     → 未匹配：仅 title + database（其余空）
  detail_url：link_map（a[href]）回填——真实结果页无锚点 → 恒 None
```

**各字段来源链**：
- year：仅来自 `_RESULT_RE` group(6)（`《来源》`段后的 4 位数字）。普通搜索页正文含“…《物理学报》…2026年12期”可命中；**高级检索内联结果页布局不同（表单/温馨提示/摘要混排），常无法命中 → year=""**。
- authors：仅来自 `_RESULT_RE` group(4)。同上，内联页常为空。
- detail_url：`_extract_title_links`（a[href]）——真实结果页标题无锚点 → None。
- citation_count：无任何来源（结果页不显示被引；详情页有“被引”但未解析）。

## 3. 缺失对链路的影响（为何必须补 year）

`FilterService._match_year`：区间非空且 `result.year` 缺失 → 删除。万方结果普遍无 year → **时间筛选一开即全删**。现有“万方缺年份来源保护”（保留 + warning）只是避免误删的止血；补齐 year 后该保护自然退化为罕见路径。
