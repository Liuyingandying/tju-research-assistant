## 6. 架构要点

### 数据流

```
ResearchReport (内存对象)
    │
    ├── export_markdown() → .md 文件
    ├── export_docx()     → .docx 文件
    └── export_pdf()      → .pdf 文件
```

### 安全保证

1. **只读操作**：导出方法只读取 `ResearchReport` 属性，不写入任何字段
2. **不调用 LLM**：`report_exporter.py` 不导入任何 LLM 相关模块（AST 验证）
3. **导出失败隔离**：异常不吞掉，原 `ResearchReport` 对象不变
4. **不修改报告文件**：导出到用户指定的新路径，不覆盖报告 JSON

### 依赖

- `python-docx>=1.0.0` — Word 导出
- `reportlab>=4.0.0` — PDF 导出（中文字体自动检测）

---

## 7. 已知限制

1. **tmp_path 环境问题**：部分测试因 `TEST_USER_DATA_ROOT` 指向 `D:\DevCache\Temp\` 导致 pytest basetemp 权限错误（pre-existing，非本次变更引入）
2. **中文字体**：PDF 导出依赖系统安装的中文字体（Windows 宋体/黑体、macOS PingFang、Linux WQY），未安装时回退 Helvetica
3. **无异步导出**：当前导出为同步操作，UI 层未使用后台线程（后续可扩展）
