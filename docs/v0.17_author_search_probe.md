## 1. CNKI：仅作者单条件（probe_cnki_author_only.py → cnki_author_only_report.json）

- 授权：`logged_in`。
- 流程：kns8s 高级检索页，主题行（row0）留空，仅填作者行（row1，默认字段=作者），
  提交后 `wait_for_advanced_result_page` 命中。
- 结果：以结果页第一个真实作者「王圣麟」为条件，返回 5 条，
  **5/5 条结果作者列表包含「王圣麟」**。
- 结论：kns8s 高级检索支持仅作者单条件提交（v0.13 起生产代码从未验证过该形态）。
- 实现落点：`cnki_advanced.CNKIAdvancedQueryBuilder.build()` 空主题时跳过 row0。

## 2. 万方：高级检索页结构改版取证（diag_wanfang_adv_dom.py → wanfang_adv_dom_diag.json）

与 v0.13 探针（`runtime/wanfang_adv_poc/form_dump.json`）对比，页面已改版：

- 可见输入行 3 个，默认字段依次为 **主题 / 题名或关键词 / 题名**
  （旧 dump 为 题名或关键词/题名/…，首行默认不再是"题名或关键词"）。
- 每行字段下拉 = `.search-option.field`（nth(i) 为第 i 行），下拉选项渲染在
  组件内部；选项全表：`全部, 主题, 题名或关键词, 题名, 作者, 作者单位, 关键词,
  摘要, 中图分类号, DOI, 第一作者, 期刊-通讯作者, 期刊-基金, …`
  → **"作者"必须用 `:text-is` 精确匹配**（has-text 会误选 第一作者/期刊-通讯作者）。
- DOM 中另有 6 个隐藏的 作者/作者单位 输入行（属"作者发文检索"页签预渲染），
  `_ADVANCED_ROWS_JS` 的 `offsetParent` 过滤可正确排除。
- 页签：高级检索 / 专业检索 / 作者发文检索。

## 3. 万方：作者字段查询形态归因（diag_wanfang_author_network.py → wanfang_author_network_diag.json）

- 高级表单 作者 行（默认模糊）提交 → gRPC-web POST
  `SearchService.SearchService/search`，查询串 `作者:(张伟)`（常见姓名）
  → **服务端返回 0 条**（页面无结果渲染）。
- 网络监听证实请求已发出且参数正确，排除表单未同步。

## 4. 万方：精确模式是作者查询的可用形态（diag_wanfang_author_render.py → wanfang_author_render_diag.json）

- row0 切「作者」+ 行内 精确/模糊 下拉（`.search-option` nth(1)）切「精确」→
  查询串变为 `作者:("吴晓东")` → **服务端响应含真实结果数据**
  （响应体内可见结果记录：PDF 链接、期刊 facet，总计数 varint ≈ 3636）。
- 结论：万方作者字段必须以精确模式提交（`作者:("姓名")`），
  模糊形态（`作者:(姓名)`）服务端恒 0。

## 5. 万方：结果渲染管线异常（diag_wanfang_render_diff.py → wanfang_render_diff.json）⚠️

- 生产现行组合（作者单位+题名或关键词）提交后渲染出 20 条，但**提交期间
  未捕获任何 SearchService 请求**——渲染的是会话中上一次普通检索的陈旧结果；
- 作者+精确 提交后 facet+search 请求均发出且服务端有数据，但 SPA 35 秒内
  未渲染 `.title-area`（页面停留表单态，`?t=` 时间戳路由跳转）；
- 「作者发文检索」页签路径同样：查询 `(作者:("吴晓东"))` 服务端有数据、页面不渲染。
- 判断：万方智搜前端自 v0.16 后发生改版（首行默认字段已变），高级检索提交的
  结果渲染管线行为与 v0.13 PoC 时代不一致。该现象**同样影响现有生产高级路径**，
  属站点侧行为，本 Phase 不做无证据的大改，列入 GUI 真机验收清单首位。

## 6. 万方：人名作导航词（probe_wanfang_author.py → wanfang_author_probe_report.json）

- 空主题场景下，普通搜索框输入人名（如「吴晓东」）可正常进入
  `/paper?q=<人名>` 结果页（`on_paper: true`）——满足高级检索首步
  "智搜域名发现"所需的导航词。
- 表单机制验证（真实页面）：row0→作者、row1→作者单位、row2→题名或关键词
  三次字段切换与逐键输入、回读全部成功。

## 7. IEEE：author 字段语法（probe_ieee_author.py / probe_ieee_author_combo.py → ieee_author_*_probe.json）

- 基线主题检索 `(terahertz OR THz)` 正常。
- 官方搜索框（`input[type=search]`）**原生解释 fielded 语法**：
  - `("Authors":"Xiaodong Feng")` → 结果按作者过滤（前 3 条作者全部命中）；
  - `("Authors":"Xiaodong Feng") AND (terahertz OR THz)` → 作者与主题双条件
    同时生效（4/4 条作者含 Xiaodong Feng 且主题为 THz）；
  - 带引号与不带引号两种写法行为一致（统一采用带引号形态）。
- 中文姓名 `("Authors":"王圣麟")` → **返回 0 条**（诚实降级，不做拼音伪造）。
- 高级检索页（/search/advsearch）可达但 Angular 表单结构未取到可用稳定锚点；
  基本框 fielded 语法已满足"真实 author 语义"，无需表单自动化。
