## 风险评估

| 风险项 | 等级 | 说明 |
| --- | --- | --- |
| 验证码 | ✅ 无 | 全程无出现 |
| 登录限制 | ✅ 无 | TJU 代理已授权，`Sign Out` 显示已登录 |
| 页面异常 | ✅ 无 | 正常返回 44,203 条结果 |
| SPA 加载问题 | ⚠️ 低 | Angular SPA，类名含 `_ngcontent-ng-*` 动态后缀，但核心 Bootstrap 类（`fw-bold`、`result-item`、`List-results-items`、`author`）稳定 |
| 作者名含结构化链接 | ⚠️ 低 | 作者名在 `<a>` 中，可用 `p.author a` 提取，`<span class="separator">` 分隔，比文本解析更稳定 |
| 年份/venue 不在当前样本 | ⚠️ 中 | 本次审计未完整抓取结果项元数据区域，需专项 DOM 审计确认 |

## 结论

**IEEE Xplore 适合作为第三个 SourceAdapter。**

- 门户进入：✅ PortalNavigator 正常打开
- 搜索：✅ `input[type=search]` + `Enter` 可靠
- 结果页：✅ 稳定 Bootstrap 结构，标题/作者可提取
- 字段：标题/作者/URL 明确可提取，年份/venue/DOI 需专项审计确认

**开发前需先做一次专项 DOM 审计**（搜索 `terahertz`，取第一条结果完整 `<xpl-results-item>` 的 outerHTML 不截断），确认：
- 年份在哪个标签中（`xpl-publication-meta`、`div.description` 或其他）
- venue 会议/期刊名称
- 是否有 DOI（搜索结果页 or 详情页）
- abstract 是否需要展开操作

## 推荐开发顺序

1. 专项 DOM 审计（年份/venue/DOI/abstract 位置确认）
2. 实现 `IeeeAdapter`（`SourceAdapter` 子类）
3. 搜索框 `input[type=search]` → `fill()` → `press("Enter")`
4. 结果解析用 `div.List-results-items` 定位项，`h3 a.fw-bold` 标题，`p.author a` 作者
5. 年份/venue 根据专项审计结果定位
6. 测试（synthetic fixture + 真实 dogfood）
