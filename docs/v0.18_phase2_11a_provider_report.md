## 3. Phase B：Provider Registry

`services/ai_provider_registry.py` — 单一事实来源，纯数据无副作用：

| id | label | default_base_url | default_model | api_key_env |
|----|-------|------------------|---------------|-------------|
| `tju_llm` | 天津大学 LLM | `https://ai.tju.edu.cn/api/v3` | `tju-llm` | `TJU_INFO_LLM_API_KEY` |
| `deepseek` | DeepSeek API | `https://api.deepseek.com` | `deepseek-chat` | `DEEPSEEK_API_KEY` |
| `custom` | 自定义 OpenAI Compatible | （空） | （空） | `TJU_INFO_LLM_API_KEY` |

API：`provider_options()` / `provider_entry()` / `default_base_url()` /
`default_model()` / `default_api_key_env()` / `endpoint_template()` /
`is_known_provider()` / `normalize_provider()`。

归一化（向后兼容）：`tju → tju_llm`、`openai-compatible → custom`、
`openai → custom`，未知 id 原样透传。

## 4. Phase C：配置系统

`api_config_manager.py`：

- `SERVICE_OPTIONS` 改为从 registry 派生，provider id 为
  `tju_llm / deepseek / custom`；
- 保留 `DEFAULT_BASE_URL` / `DEFAULT_MODEL`（= tju_llm 默认，`test_api_config_manager.py`
  继续通过）；
- `load_config` 读入后对 `provider` 做 `normalize_provider`（旧配置平滑迁移）；
- `set_from_settings` 归一 provider id，且 base_url / model 缺失时回退到
  **该 provider 的默认值**（DeepSeek 无需手填即可用）；
- `provider_config()` 返回结构不变（SummaryService / ReportService 零改动）。

DeepSeek 配置示例（任务书）已支持并验证：

```json
{ "provider": "deepseek",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-chat" }
```

---

## 5. Phase D：SettingsDialog

- `combo_service` 三项：天津大学 LLM / DeepSeek API / 自定义 OpenAI Compatible；
- `_on_service_changed`：对**任一已知 provider** 自动填充 base_url / model
  （custom 清空并保留占位提示手动填写）；
- `_provider_cfg_from_form` / `_on_save`：fallback 到当前所选 provider 的
  默认 base_url / model / api_key_env（不再是固定 DEFAULT）；
- Key 继续经 `CredentialStore`（keyring → DPAPI → memory-only），不因
  多 provider 新增明文。

## 6. 测试

### 6.1 新增测试

| 文件 | 项数 | 覆盖 |
|------|------|------|
| `tests/test_ai_provider_registry.py` | 16 | 三个内置 id、默认值、下拉选项、旧 id 归一、endpoint 模板、副本独立性 |
| `tests/test_multi_provider.py` | 18 | Provider 切换、配置保存（DeepSeek 示例回读）、Key 隔离、SettingsDialog 自动填充、无侵入验证 |

关键断言：
- `set_from_settings("deepseek","","",key)` → base_url=`https://api.deepseek.com`、model=`deepseek-chat`；
- 切换 provider 后 API Key 不进 config JSON（`"api_key"` 不在文件，key 仍在 mock keyring）；
- 切换 provider 不清空已保存 key；`api_key_env` 随 provider 变化；
- SettingsDialog 选择 DeepSeek 后 `input_base_url`/`input_model` 自动填充；
- `SummaryService(config=mgr.provider_config()).enhanced_configured is True`；
- `OpenAICompatibleProvider(mgr.provider_config())` 直接消费 DeepSeek 配置
  （`model=="deepseek-chat"`、`provider_name=="deepseek"`）。
