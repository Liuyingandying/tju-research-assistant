  **可匿名构造 URL**（token=tourist），亦可走 UI 输入框交互（两种路径均验证）。
- 结果：**约 15 条**，均为天津大学相关科研新闻的中央媒体转载与校园报道：
  1. 健康报：太赫兹和声波结合使无针血钠检测成为可能（媒体聚焦 健康报-2025-07-17）
  2. 科技日报：太赫兹光声系统实现血钠无创实时监测（媒体聚焦 科技日报-2025-07-17）
  3. 新华社：太赫兹+声波！我国科学家使无针血钠检测成为可能（田震教授团队）
  4. 中宏网：太赫兹光声检测取得新突破 …
- 相关性 ✓：全部围绕太赫兹科研进展。

## 6. 页面结构（探针 03/04/05 json）

- 搜索页：`div.listBox > ul > li/div.syqbwzzs_templ` 每条含
  `a.title`（无 href，JS 跳转）+ 摘要段 + 「分类 媒体-日期 时间」行；
- 详情页：`/info/<栏目id>/<文章id>.htm` 经典稳定 URL，含标题/日期/来源/作者/正文；
- 搜索 URL 的 query 为 base64(JSON)，匿名可构造（潜规则：不走 UI 也可直达）。

## 7. 页面稳定性

- 搜索：URL 构造直达 + 首次加载即含结果（无陈旧渲染、无复杂 remount）；
- 详情：点击标题新标签打开（expect_page 捕获成功），经典静态页；
- 多轮探针（6 次独立运行）结果一致，无验证码、无频率限制迹象。

## 12. Adapter 预计成本（低-中）

- 搜索 URL 构造（base64 JSON + 匿名 token）或 UI 交互两路皆可；
- 列表解析：`a.title` + 条目行正则（媒体-日期）+ 摘要段；
- detail_url：点击标题新标签捕获（与专利 resolver 同型）；
- 无需登录态、无反爬对抗、readiness 简单（首次加载即含结果 + 统计条"约 N 个"）。

## 14. 风险

1. 搜索范围限于天大新闻网（含转载）——对非天大关联的研究方向命中可能少；
2. `soso.html?query=` 的 base64 payload 结构与 owner/token 属站点内部约定，
   改版风险由"UI 交互路径"兜底（两路皆已验证）；
3. 列表标题 `a.title` 无 href → detail_url 需点击捕获（resolver 模式，既有先例）；
4. 详情页作者署名仅部分文章有（可缺，unknown 保留语义已就绪）。
