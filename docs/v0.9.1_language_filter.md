# v0.9.1 Language Filter 实现

日期：2026-09-03　状态：完成（实现 + 测试 + 真实验证）

## 1. 设计

语言筛选控制**检索结果语言范围**（非用户输入语言），完全在 GUI 层实现，
未改动 Adapter / QueryTranslator / QueryBuilder / SearchService。

### 语言模式定义

| mode | 按钮 | 允许来源 | 禁用来源 |
| --- | --- | --- | --- |
| `zh` | 中文 | CNKI、万方 | IEEE Xplore |
| `en` | English | IEEE Xplore | CNKI、万方 |
| `bilingual` | 中英双语（默认） | 三者全部 | 无 |

### 实现要点（main_window.py）

- 三个 `QToolButton#langButton`（checkable）加入 `QButtonGroup(exclusive=True)`，
  存入 `self.lang_buttons = {"zh":…, "en":…, "bilingual":…}`；
  **默认选中「中英双语」**；`buttonClicked → _apply_language_mode` 联动。
- 新增只读属性 `MainWindow.language_mode -> "zh"|"en"|"bilingual"`（由选中按钮映射）。
- `_apply_language_mode()`：仅切换来源复选框 `setEnabled`，**不改勾选状态**——
  被禁用来源的既有勾选保留，切回允许模式时自动恢复（满足“状态保存”要求）。
  `_build_ui` 末尾调用一次以同步初始态。
- `_on_search()` 在构造 `QueryRequest` 前过滤：
  `sources = [名 for 复选框 if isChecked() and isEnabled()]`。
  被禁用来源即使勾选保留也不会发出请求（如 English 下勾选 CNKI+IEEE → 只发 ieee）。
  过滤后为空时由既有 `QueryRequest.validate()` 提示“请至少选择一个数据来源”。
- 语义注记：`SearchService.search` 会无条件打开 CNKI 频道页（既有编排流程，
  本轮不改）；“只访问某库”约束作用于**适配器级检索**，真实验证按适配器调用记录。

### 视觉（theme.py QSS）

- 未选中：白底、蓝字 `#1a5cb0`、浅蓝描边；
- 选中（`:checked`）：天大蓝底 `#1a5cb0`、深蓝描边 `#14488f`、白字、加粗；
- hover/禁用态保留原基调。语言按钮 tooltip 注明各模式可用来源。

## 3. 测试结果

新增 `tests/test_language_filter.py`（offscreen，unittest，与既有 GUI 测试同约定）：

1. **默认模式** `test_default_mode_bilingual`：bilingual + 三来源均可用 + 按钮均可勾选；
   另有 `test_language_buttons_exclusive` 验证互斥。
2. **中文** `test_zh_mode_excludes_ieee`：IEEE 禁用；即便 IEEE 勾选保留，
   发出的 `query.sources == ["CNKI", "万方"]`。
3. **English** `test_en_mode_only_ieee`：CNKI/万方禁用；三源全勾选仍只发
   `["IEEE Xplore"]`。
4. **切回双语** `test_back_to_bilingual_restores_all`：CNKI+IEEE 勾选 → 切 en
   （CNKI 禁用、勾选保留）→ 切回：全部恢复且勾选不变。
5. **中文输入 + English** `test_chinese_input_en_mode_reaches_translator_and_builder`：
   请求原样携带中文关键词与 ieee 来源；并按 SearchService 同一链路
   （Expansion → Translator → Builder）离线复算，IEEE 布尔串 =
   `(terahertz OR THz) AND (communication)`。

排障记录：首轮运行挂起，定位为 `test_back_to_bilingual_restores_all` 未填研究
方向即调 `_on_search()`，触发模态 `QMessageBox`（offscreen 下永不返回）；
补入输入文本后解决，与产品代码无关。

全量回归：`python -m pytest -q` → **265 passed**（27.75s；v0.9.0 基线 259 + 新增 6）。
README 中的 259 口径标注为 v0.9.0 时点数据，本轮未动版本号，封版时统一同步。

## 4. 真实验证（受控 Edge + TJU 授权会话，太赫兹通信 / 综合 / 10 条）

脚本 `runtime/validate_language_filter.py`（gitignored）：以 Recording 适配器
包装三来源注册表，记录 `SearchService` 实际下发的检索串（运行时观察，不改源码）。
完整日志：`runtime/lf_real_log.txt`。

**Case 1 — language=English, source=IEEE**
- 实际执行来源：`['IEEE Xplore']`（CNKI/万方零调用）
- IEEE 收到检索串：`(terahertz OR THz) AND (communication)` ✅ 与预期逐字符一致
- 返回 10 篇论文，示例：
  - Multi-Source Direction of Arrival Estimation in Terahertz Communications Using CNN (2025, IRMMW-THz)
  - Terahertz Communications Based on Resonant Tunneling Diode (2025, IMWS-AMP)
  - Performance Analysis of Single Carrier Modulation Schemes in Terahertz Communications (2024, IRMMW-THz)

**Case 2 — language=中文**
- 实际执行来源：`['CNKI', '万方']`（IEEE 零调用）✅
- 返回 20 条，示例：基于软件无线电的低轨星间太赫兹通信宽带正交调制技术（CNKI, 2026）、
  光电融合智能太赫兹通信与感知（万方, 2026）

**Case 3 — language=中英双语**
- 实际执行来源：`['CNKI', 'IEEE Xplore', '万方']` ✅ 中文库与 IEEE 均执行
- IEEE 收到 `(terahertz OR THz) AND (communication)`；中文库收到原词；合并去重排序正常。

## 5. 结论

语言筛选已正式接入基础检索流程：UI 互斥选择、默认双语、来源联动与状态保留、
请求前过滤、跨语言链路不受影响；离线 265 测试与三组真实验证全部符合任务验收口径。
