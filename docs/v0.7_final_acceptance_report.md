## 2. 项目定位

天津大学信息自动检索整理系统是面向天津大学正常授权用户的科研信息检索辅助桌面应用。系统通过受控 Microsoft Edge 复用天津大学图书馆授权会话，对学术数据库执行正常、低频、用户主动发起的检索，并将结果统一结构化、去重、排序、展示和导出。

项目边界明确：它不是批量下载器或通用爬虫，不自动登录，不绕过验证码、认证或数据库访问控制，不读取或输出 Cookie、token、认证 header，也不自动下载全文/PDF。v0.7.0 为无 AI 的基础模式，AI Mode 尚处于规划阶段。

## 4. 技术架构

系统采用分层桌面架构：

```text
PySide6 MainWindow（主线程）
        │ Qt queued signals
        ▼
BrowserWorker（QThread）
        │
        ▼
SearchService（检索编排）
 ├─ QueryExpansionService
 ├─ AdapterRegistry
 │   ├─ CNKIAdapter
 │   ├─ WanfangAdapter ─┐
 │   └─ IeeeAdapter ────┴─ PortalNavigator
 ├─ ResultMerger
 └─ RankingService
        │
        ▼
BrowserSession（Playwright sync API）
        │
        ▼
本机 Microsoft Edge + runtime/edge_profile
```

主要技术边界：

- **界面层**：PySide6；主线程负责输入、展示、导出和报告操作。
- **执行层**：BrowserWorker 位于独立 QThread；Playwright 操作不占用 GUI 主线程。
- **浏览器层**：Playwright sync API 驱动本机 Edge，启用 Chromium sandbox，使用项目专用持久 Profile。
- **编排层**：SearchService 负责查询扩展、数据源路由、结果融合与排序。
- **适配层**：所有来源实现统一 `SourceAdapter.search(keyword, count)` 接口。
- **门户层**：PortalNavigator 等待登录回跳至 `p.lib.tju.edu.cn`，并等待分类入口和 Angular 资源节点初始化后再定位资源。
- **输出层**：统一结果模型驱动表格展示、JSON/CSV/Markdown 导出和 Markdown 报告。

## 9. 已知限制

- 万方作者文本可能无分隔符，无法可靠拆分为独立作者列表。
- CNKI、万方结果页不总是提供 DOI 和 abstract；v0.7.0 不进入详情页补抓这些字段。
- 维普代理落地页曾出现 SPA 空白，未纳入正式数据源。
- 多源检索顺序执行，总耗时随来源数量线性增加。
- 受 Playwright sync API 与 QThread 生命周期约束，浏览器任务可能重建 Edge 会话；授权由专用 Profile 保留，但窗口可能闪现。
- 检索结果只保存在内存或用户主动导出的文件中，没有检索历史数据库。
- 演示数据不提供真实 detail URL，避免打开虚构页面。
- 自动登录、自动翻页、批量抓取和全文/PDF 自动下载均不支持。
- 人员姓名和单位字段尚未作为真实检索条件参与查询。
- 程序结果与来源页面前 3 条的人工 cross-check 在现有发布材料中仍标记为 PENDING。
- 第三方数据库 DOM、TJU 登录页和资源代理属于外部依赖，升级后可能需要重新审计 selector 与等待条件。

## 10. 后续 AI Mode 规划

AI Mode 应作为独立、可选、默认关闭的增强层接入，并保持现有无 AI 链路完整可用。建议分阶段实施：

1. **AI 摘要**：基于用户明确选择的检索结果生成中文摘要、核心发现和研究脉络。
2. **语义重排**：使用 embedding 或 reranker 对现有规则排序结果进行可解释的二次排序。
3. **相关度筛选**：按研究方向标注文献相关度、主题标签和排除理由，由用户决定是否过滤。
4. **证据追踪**：所有 AI 结论保留对应题录、摘要来源和生成状态，区分原始字段与模型生成内容。
5. **隐私与授权门**：外部模型调用必须显式开启；发送前展示数据范围并取得用户同意，不发送 Cookie、token、认证信息或未选择的全文内容。
6. **降级与隔离**：AI 服务不可用时回退到 v0.7.0 基础模式；AI 错误不得影响检索、导出、报告和全文页面功能。
7. **独立验收**：为 provider mock、隐私门、失败降级、输出标注建立自动测试；真实模型效果另以人工样本和可复现实验验收，不用 mock 结果冒充真实 AI 能力。

AI Mode 不应在 v0.7.0 发布收口阶段直接加入；建议作为后续独立版本进行设计、实现和验收。
