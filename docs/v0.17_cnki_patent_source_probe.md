## 6. 详情页成本与风险

- 详情页：直接 URL 打开（新标签，无需模拟点击）；字段：专利类型/申请号/
  申请日/授权公告号/授权公告日/申请人/地址/发明人/主分类号/分类号/代理机构/
  代理人/主权项；
- **软反爬风险**：详情页文本含“安全验证/拖动”元素（06 json captcha_match）
  ——本次打开未阻断内容，但属频率相关风险；**Adapter 必须坚持 bounded 低频
  （≤8 条/次）**，与万方 resolver 同约束；
- 详情 enrichment 需求：公开号/摘要/IPC 三项（1 次详情/专利）。

## 7. 组合语义

- 落地页芯片为单字段；topic+inventor 等组合**未在本 PoC 验证**——
  候选路径：结果页“结果中检索”或两次搜索交集（与新闻组合同思路）；
  列入 Phase 2.2-F 实现前的小探针，不预断。
