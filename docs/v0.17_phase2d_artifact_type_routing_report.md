# v0.17 Phase 2.2-D 报告：成果类型选择与 PatentAdapter GUI 生产可达性

日期：2026-09-07
范围：GUI「成果类型（论文/专利）」选择 + 论文×专利联合检索 + 万方专利经生产链
GUI 可达；strict 基于 resolve 后 effective sources 判定。
未实施：新闻/著作/获奖、artifact-level quota、第二套 SearchService、Ranking/citation 改造。

## 1. UI 设计

检索卡片新增「成果类型」行（位于 人员姓名/单位 与 数据来源 之间，现代蓝白风格）：

```
成果类型： ☑ 论文  ☐ 专利
```

- 默认：论文 checked、专利 unchecked（旧用户不操作时行为完全兼容）；
- 与「数据来源」正交（数据来源区未新增任何“万方专利”复选框——内部 source 名
  不作数据库复选框出现，避免 artifact type 与 database source 混为一谈）；
- 专利复选框 tooltip 说明：目前仅支持万方数据源；高引用排序主要依据论文被引
  信息，无被引数据成果按现有综合规则降级排序。

## 2. source ≠ artifact_type 语义

`services/artifact_routing.py`（纯函数，可测试）持有映射表：

| 成果类型 | 数据库 | 内部 source |
| --- | --- | --- |
| paper | CNKI / 万方 / IEEE Xplore | 同名（原样透传） |
| patent | 万方 | 万方专利 |
| patent | CNKI / IEEE Xplore | 无（当前无 adapter） |

「万方专利」是生产内部标识（citation_selector 按 database 分组、需与独立 source
quota 一致），只在请求内部 source list 中出现，不进入数据库复选框。

## 3. effective source resolver

`resolve_effective_sources(selected_databases, selected_artifact_types)`：
保序、去重；成果类型为空按 paper 处理（默认兼容）。GUI 在提交前调用，
SearchService 只接最终内部 sources（QueryRequest/Worker/SearchService 零改动）。

## 4. 映射矩阵（测试锁定）

| 成果类型 | 数据库 | effective sources |
| --- | --- | --- |
| paper | CNKI, 万方 | CNKI, 万方 |
| paper | CNKI, 万方, IEEE Xplore | CNKI, 万方, IEEE Xplore |
| patent | 万方 | 万方专利 |
| paper+patent | 万方 | 万方, 万方专利 |
| paper+patent | CNKI, 万方, IEEE Xplore | CNKI, 万方, IEEE Xplore, 万方专利 |
| patent | CNKI / IEEE Xplore | []（阻止） |

## 5. 默认兼容

默认（论文 + CNKI，旧 GUI 默认状态）→ request.sources == ["CNKI"]，
与改动前逐项一致；多源默认、语言模式默认也由既有 GUI 测试回归锁定。

## 6. strict 处理

strict-gate 判定从「UI 上 IEEE checkbox 是否勾选」改为「resolve 后
effective sources 是否含 IEEE Xplore」：
- 仅专利 + 万方+IEEE 复选框 + strict → effective=[万方专利] → **不误杀**（测试锁定）；
- 论文+专利 + 万方+IEEE + strict → effective 含 IEEE Xplore → **仍阻止**（测试锁定）；
- 中文模式 strict 无 IEEE → 不阻止（既有行为不变）。

## 7. language 处理

未改动 中文/英文/中英双语 任何行为（`_apply_language_mode` 仅控制数据库复选框
enabled，与既有一致）。语言 × 成果类型组合无有效 adapter 时给出明确提示——
例如英文模式（万方禁用）+ 仅专利 → effective=[] → 提示“当前专利检索仅支持
万方，请勾选万方数据源。”（测试锁定）。

## 8. PatentAdapter 生产可达性

`SearchService._default_registry` 已注册「万方专利」→ WanfangPatentAdapter；
GUI 勾 专利+万方 → effective 含「万方专利」→ QueryRequest.sources →
worker → SearchService 按 registry 实例化 WanfangPatentAdapter（位置参数
count + query_context 传递经测试锁定）。无第二套 SearchService。

## 9. 联合检索

论文+专利 + 万方 → sources=["万方", "万方专利"]，SearchService 视为两个独立
source：独立 quota 均分、独立 adapter 调用、独立 artifact_type 结果（Merger
类型感知去重不跨类型互吞）。专利 citation_count=None → CITATION 模式按既有
全 None 综合分回退。

## 10. 不支持组合反馈

- 仅专利 + 无万方 → 阻止弹窗「当前专利检索仅支持万方，请勾选万方数据源。」；
- 论文+专利 + 无万方 → 非阻断状态栏提示「提示：所选来源中没有支持专利检索的
  数据库，本次仅检索论文。」并继续论文检索；
- 无任何有效来源 → 阻止弹窗「请至少选择一个可执行的数据来源。」。
以上全部复用既有 QMessageBox / 状态栏，未新增弹窗体系。

## 14. 用户真机验收清单（由用户本人执行，不使用 computer-use）

1. **默认论文模式**：不勾专利，按旧习惯检索（CNKI/万方/IEEE、中英双语、综合/
   最新/高引用、strict）→ 与 Phase 2.2-C 前行为一致；
2. **仅专利 + 万方 + 研究方向“太赫兹”** → 结果类型列为「专利」、来源列
   显示「万方专利」、发明人/申请人/公开号字段正确、可打开详情；
3. **仅专利 + 万方 + 人员姓名“殷贤华”** → 返回其专利；
4. **论文+专利 + 万方** → 同时出现 paper（来源 万方）与 patent（来源 万方专利）；
5. **仅专利 + CNKI** → 弹「当前专利检索仅支持万方，请勾选万方数据源。」；
6. **仅专利 + 万方+IEEE + 严格匹配** → 不误杀（可进入检索）；
   论文+专利 + 万方+IEEE + 严格匹配 → 仍被拦截。

## 15. 剩余风险

1. **多源均分 quota**（20 → 4×5）会使论文单源结果变少——课程演示可接受，
   artifact-level quota 留作可选优化（本阶段明确不实现）；
2. 专利发明人 enrichment 上限 8 条/次，CITATION 候选扩大时非前 8 条无发明人列
   （unknown 保留）；
3. 语言模式 × 专利组合的提示文案对用户可能略生硬（英文+仅专利直接弹万方提示），
   属“明确反馈”范畴，可后续润色；
4. 万方门户授权过期仍会中断真机链路（既有环境风险）。

——Phase 2.2-D 完成，按约定停止，不自动开始新闻 Phase。

## Hotfix 记录（2026-09-07，人工 GUI 验收 Case B）

**问题**：人工 GUI 验收发现——论文❌ 专利❌ + 万方 ✅ 点击检索时，系统自动回退
paper 并执行万方论文搜索返回期刊论文；预期是阻止并提示"请至少选择一种成果类型。"。

**根因**：`resolve_effective_sources` 中 `list(selected_artifact_types) or [ARTIFACT_PAPER]`
把 falsy 值统一回退 paper——**未区分 None 与 []**：显式空列表（GUI 全未勾选）被当作
"未提供"而默认论文。附带缺陷：`list(None)` 本会 TypeError（legacy None 调用方从未被正确处理）。

**None vs [] 语义**（修复后）：
- `selected_artifact_types is None` → legacy 调用方未提供 → 默认 `["paper"]`（旧调用兼容）；
- `selected_artifact_types == []` → 明确选择零种成果类型 → 返回 `[]`，不回退 paper
  （GUI 已在提交前单独阻止全未勾选，此处为防御语义）。

**修改文件**：
- `services/artifact_routing.py`：None/[] 分支 + docstring 语义说明；
- `ui/main_window.py`：`_on_search` 成果类型全未勾选 → 阻止 + "请至少选择一种成果类型。"；
- `tests/test_artifact_source_routing.py`：新增 3 条（None legacy / [] 不回退 /
  GUI 全未勾选阻止+精确文案+不发请求），原 `test_default_no_artifact_is_paper`
  按新语义改写为 None 版本。

**未触碰**：SearchService / WanfangPatentAdapter / WanfangAdapter / FilterService /
RankingService / citation_selector / Worker / QueryRequest / 语言模式。
