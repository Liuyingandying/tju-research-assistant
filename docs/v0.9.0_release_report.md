# v0.9.0 Release Report（现代学术风 UI）

> 发布日期：2026-09-03。
> 上一版本：v0.8.2（跨语言科研检索系统）。
> 本版本主题：UI 现代化重构 —— 校徽 Header / 检索卡片 / 状态指示 / 空态引导 / QSS 主题。

---

## 一、版本定位

v0.9.0 是**呈现层现代化版本**：在不改变任何检索能力的前提下，把界面从"系统默认样式的 MVP 形态"升级为"高校科研平台风格的现代学术界面"。

- 与 v0.8.2 的关系：v0.8.2 交付跨语言检索能力（ConceptSegmenter / Terminology / QueryTranslator / QueryBuilder / IEEE Metadata Parser）；v0.9.0 只重塑其外观与交互观感，检索链路、线程模型、信号契约完全复用。
- 版本策略：单线语义化版本（v0.7.1 → v0.8.2 → v0.9.0），`version.py` 统一驱动 GUI 关于对话框、检索报告抬头与验收脚本，不设后端/UI 双版本号。

### 2.2 功能性改进

1. **全局 QSS 主题**：`ui/theme.py` 承载色板 + 样式表，按 objectName 精确作用，可整体替换（夜间模式预留）。
2. **程序化矢量图标**：放大镜/盾牌/外链/下载/文档/数据库/信息/徽标/空态插画全部 QPainter 绘制，零二进制资源、零新依赖；徽标为"TJU · 1895"双环学术圆章（不伪造官方校徽）。
3. **状态动态指示**：状态条图标与文字按语义变色（绿=授权正常/完成，红=失败/错误，蓝=进行中）。
4. **空态引导**：结果为空时表体内显示收纳盒插画 + "请设置检索条件并开始检索"（保留表头）。
5. **语言筛选占位**：分段按钮组（中文/英文/中英双语）按项目惯例展示选中态并置灰，标注"下一阶段开放"。
6. **应用字体**：`main.py` 统一设置 Microsoft YaHei 10pt。

## 五、已知限制

1. **语言筛选为占位控件**：分段按钮可见但置灰（"下一阶段开放"），点击无检索语义；待后续版本定义中英文分流检索需求后接入 QueryRequest。
2. **QComboBox 下拉箭头保持原生样式**：Qt QSS 定制箭头需图片资源（`url()`），本项目零二进制资源约束下未定制；输入框主体已按主题着色。
3. **对话框样式部分继承**：`QMessageBox` / `QFileDialog` 继承全局 QSS 的通用选择器（输入框/表格），但其按钮因 objectName 不匹配保持原生外观。
4. **徽标为占位设计**："TJU · 1895" 双环圆章为程序化绘制的学术风占位，非官方校徽；如需官方视觉资产，需另行获取授权并引入 `.qrc` 资源。
5. **v0.9.0 变更尚未 git 提交**：本报告完成时工作树包含 UI 重构与版本同步变更，发布提交（建议 `feat: release v0.9.0 modern academic UI`）为下一步待办。
6. **视觉回归为人工核验**：预览截图（`runtime/ui_preview_*.png`，gitignored）由本地脚本生成，未纳入自动化视觉测试。
