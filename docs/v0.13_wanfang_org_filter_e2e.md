## 3. 根因（真机实测定位）

生产 `WanfangAdapter._advanced_search`（本轮 E2E 未获修改，按现场同序复测）与探针同为：
`page.locator(".ivu-input").first.press_sequentially(affiliation)` + `.nth(1).press_sequentially(keyword)`。
真实高级检索页的 `.ivu-input` 数量为 **11**（非单测假页的 3），`.first/.nth(1)` 选择器**不与行输入框对齐**——
这是单测假页结构偏简未暴露的真实缺陷（单测只验证了“键盘事件与提交前校验”语义，未验证真实 DOM 布局）。

另计环境因素：本 E2E 曾遇 **TJU SSO 会话过期**（门户跳转 `user.lib.tju.edu.cn/#/login`），重跑后授权恢复正常，非本功能缺陷。
