## 1. GUI 失败复现与根因

**生产 selector**（`wanfang.py` `_ADV_TIME_ROW`）：
```
div.hrafwidth:has(span.title:text-is('发表时间：'))
```
**实测命中数：0（三种页面状态下均为 0）**——GUI 报错“未找到‘发表时间’行控件”即此。

**根因：标签名错配。** 真实 DOM 中“发表时间”行的结构链为：

```
SPAN.title（文本“发表时间：”）
  ⊂ SPAN.hrafwidth        ← hrafwidth 是 SPAN 的 class，不是 DIV！
  ⊂ DIV.time-select       ← 该行真正的行容器
  ⊂ DIV（外层布局容器）
```

生产 selector 要求 `div.hrafwidth`（hrafwidth 须为 DIV），而真实元素是 `<SPAN class="hrafwidth">` —— CSS 按标签名过滤，**永不匹配**。该 class 亦非构建哈希（多会话稳定），是纯粹的标签写错。
