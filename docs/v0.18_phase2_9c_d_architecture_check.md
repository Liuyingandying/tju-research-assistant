# v0.18 Phase 2.9-C-D-A —— LLMReportProvider 架构审计

- 阶段：Phase 2.9-C-D-A（实现前审计）
- 日期：2026-09-11
- 结论：**ReportService 无需修改即可从 Mock 切换到 LLMReportProvider**；
  新增 Provider 只经 `OpenAICompatibleProvider` 出网，不直接使用 requests。

---

## 1. ReportService 的 Provider 调用点（换 Provider 零改动）

`services/report_service.py` 对 Provider 的全部使用：

| 调用点 | 需要的属性/方法 |
|---|---|
| `self.configured` | `provider is not None` |
| `self.provider_name` | `provider.name` |
| `self._provider.generate(context)` | `generate(ReportContext) -> ResearchReport` |
| `self._cache_key` | `provider.name` + `provider.model` |
| `self._provider_calls()` | `provider.calls` |
| `_normalize` / `_finalize` | `provider.model` |

`MockReportProvider` 与 `LLMReportProvider` 均实现上述契约 →
**`ReportService` 一个字节都不用改**（已有 `test_service_swap_requires_no_change`
守护：同一 service 对象直接换成 LLMReportProvider 后正常生成）。

## 3. 数据流

```
ReportContext（ReportSource 快照集合 + 画像快照）
    ↓ build_report_prompt()           ← r1：<PAPERS> + <USER PROFILE> + 六章节
    ↓ OpenAICompatibleProvider.complete(prompt, system_prompt=r1)   ← 唯一网络出口
    ↓ parse_report_sections(raw, context)
    ↓ ResearchReport(title + sections；source_papers 映射为论文 id)
    ↓（ReportService.validate_sources + 填充元信息 + 保存 + 缓存）
```

- Provider 失败**向上抛**：`LLMConfigError` / `LLMNetworkError` / `LLMHTTPError` /
  `LLMTimeoutError` / `ReportParseError` / `ReportGroundingError`；
- `ReportService` 分类降级（C-D 新增细分）：
  `ReportGroundingError → source_validation`、`ReportParseError → parse`、
  其余 → `provider_error`；
- 缓存 key 已含 `REPORT_PROMPT_VERSION`（`report_cache.py` 未修改，确认存在）。

---

## 4. 与单篇链路的关系

- **不触碰**：`SummaryService` / `EnhancedSummary` / `LibraryRecord` schema /
  `SearchService` / Evidence 链 / `OfflineSummaryEngine`；
- 报告与单篇共享的只有"同一个 `OpenAICompatibleProvider` 类"，
  代码上零耦合（`llm_report_provider.py` 不 import 单篇 prompt / summary 模块）；
- 缓存命名空间不同（`research_reports/` vs `enhanced_summary/`），
  Prompt 版本不同（`r1` vs `v4`）。

---

## 5. 本阶段未做（边界）

UI / Markdown 导出 / 批量选择 / EXE 打包；以及"批量任务队列"。
未修改：`ReportCache` / `ReportProvider` 协议 / `ReportContext` /
`ResearchReport` 模型 / 单篇链路。

> 说明：`ReportService` 在本阶段有一处**正交改进**（非 Provider 切换所需）：
> 为满足 C-D "JSON 解析失败由 Service 统一降级" 并让降级原因可区分，
> 新增对 `ReportGroundingError → source_validation`、`ReportParseError → parse`
> 的分类。**切换 Provider 本身不需要任何 Service 改动**（`test_service_swap_requires_no_change`
> 守护该契约）。
