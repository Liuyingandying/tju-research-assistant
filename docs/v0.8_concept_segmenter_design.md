## 一、当前 QueryTranslator 的概念识别流程

### 1.1 `_concepts_for`（`query_translator.py:77`）

```python
def _concepts_for(self, expanded: ExpandedQuery) -> list[list[str]]:
    """把原始研究方向按词元切分，每个词元映射为英文等价词（未命中保持原样）。"""
    concepts: list[list[str]] = []
    for piece in expanded.original.split():
        en = TERMS.get(piece, {}).get("en")
        if en:
            concepts.append(list(en))
        else:
            concepts.append([piece])
    return concepts
```

**当前切分逻辑**：`expanded.original.split()`——**仅按空白切分**。每个空白分隔的片段作为一个词元，查 `TERMS` 命中则替换为英文等价词，未命中则保持原样。

### 1.2 `TERMS` 查询方式

```python
TERMS = {
    "太赫兹":   {"en": ["terahertz", "THz"]},
    "通感一体化": {"en": ["integrated sensing and communication", "ISAC"]},
}
```

`TERMS.get(piece, {}).get("en")`——**整词精确匹配**。只有 `piece` 与 `TERMS` 的 key **完全相等**才命中；无前缀/子串匹配，无最长匹配。

### 1.3 调用链

```
translate_concepts(expanded, sources)
  → 英文源: _concepts_for(expanded)     # 概念分组
  → 中文源: [[expanded.query_string]]    # 透传
_concepts_for → expanded.original.split() → 逐词元查 TERMS
```

### 1.4 问题根因

| 问题 | 根因 |
| --- | --- |
| 问题 1：`太赫兹通感一体化` 不切分 | `split()` 只按空白切分，无空格 → 整串 `太赫兹通感一体化` 作为一个词元 → 未命中 `TERMS` → 保持原样（纯中文） |
| 问题 2：`太赫兹通信` 不拆分 | 同上；且 `TERMS` 无 `通信`→`communication` 映射，即使切分 `通信` 也缺英文词 |

**实测确认**（`v0.8_cross_language_acceptance_plan.md`）：

```
'太赫兹通感一体化': concepts=[['太赫兹通感一体化']] -> '(太赫兹通感一体化)'
'太赫兹通信':       concepts=[['太赫兹通信']]       -> '(太赫兹通信)'
'量子计算':         concepts=[['量子计算']]         -> '(量子计算)'
```

## 二、设计中文科研关键词切分模块

### 2.1 方案 A：简单空格 split（当前）

- **准确率**：低。只处理有空格输入；`太赫兹通感一体化`（无空格）不切分。
- **依赖**：无。
- **对现有测试影响**：无（就是当前实现）。

**结论**：不解决任何问题，仅作对照基线。

### 2.2 方案 B：基于 `TERMS` 最长匹配（**推荐**）

**算法**：从文本每个位置，尝试匹配**最长**的 `TERMS` 词典词；命中则切为一个概念并跳过；未命中则**累积连续未命中字符为一段**（避免逐字碎片）。

```python
def segment(text: str, dictionary: set[str]) -> list[str]:
    """词典最长匹配切分：命中最长词，未命中累积为一段。"""
    concepts: list[str] = []
    i = 0
    while i < len(text):
        matched = None
        for j in range(len(text), i, -1):        # 从最长到最短
            if text[i:j] in dictionary:
                matched = text[i:j]
                break
        if matched:
            concepts.append(matched)
            i += len(matched)
        else:
            start = i                            # 累积连续未命中为一段
            while i < len(text):
                if any(text[i:k] in dictionary for k in range(i + 1, len(text) + 1)):
                    break
                i += 1
            concepts.append(text[start:i])
    return concepts
```

**对两个问题的效果**（`dictionary = {"太赫兹", "通感一体化"}`）：

| 输入 | 切分结果 | 说明 |
| --- | --- | --- |
| `太赫兹通感一体化` | `[太赫兹, 通感一体化]` | 最长匹配：`太赫兹`（3 字）+ `通感一体化`（5 字） |
| `太赫兹通信` | `[太赫兹, 通信]` | `太赫兹` 命中；`通信` 未命中 → 累积为一段（非逐字 `通`+`信`） |
| `量子计算` | `[量子计算]` | 全未命中 → 整段保留（安全回退） |

**准确率**：中高。对 `TERMS` 覆盖的词元**确定性正确**（最长匹配避免错误切分）；未命中词元保留为整段（不产生错误碎片）。**准确率上限取决于 `TERMS` 覆盖率**——`通信` 若加入 `TERMS`（→`communication`），`太赫兹通信` 才能完整翻译；否则 `通信` 保留中文。

**依赖**：无。纯 Python，复用现有 `TERMS` 作为词典，零新增依赖。

**对现有测试影响**：低。`_concepts_for` 的输入输出接口不变（仍是 `list[list[str]]`）；现有 `test_query_translator.py` 的用例（`太赫兹 通感一体化` 有空格、`通感一体化`、`量子计算`）在最长匹配下结果**不变**（有空格输入切分一致；`量子计算` 仍整段）。仅当输入为**无空格复合中文词**时才产生新行为。

### 2.3 方案 C：引入第三方分词库（如 jieba）

- **准确率**：高（通用中文）。但对**科研领域词**（`太赫兹`、`通感一体化`）**不认识**，需额外加载自定义词典；且可能**过度切分**领域复合词（如把 `通感一体化` 切成 `通感`/`一体化`）。
- **依赖**：**重**。新增 jieba 依赖（含其词典数据），违背项目"最小依赖"哲学（当前仅 playwright + PySide6 + pytest）。
- **对现有测试影响**：中。新依赖、更慢、跨版本结果可能非确定；领域词切分需自定义词典维护。

**结论**：不推荐。领域词是核心，通用分词库反而不认识，且引入重依赖与不确定性。

### 2.4 方案对比

| 维度 | 方案 A（空格 split） | 方案 B（TERMS 最长匹配） | 方案 C（第三方分词库） |
| --- | --- | --- | --- |
| 准确率 | 低 | 中高（取决于 TERMS 覆盖） | 高（通用）/ 低（领域词） |
| 依赖 | 无 | **无** | 重（jieba） |
| 确定性 | 是 | 是 | 跨版本可能非确定 |
| 领域词支持 | 差 | **好**（TERMS 即领域词典） | 差（需自定义词典） |
| 对现有测试影响 | 无 | 低 | 中 |
| 推荐度 | 不推荐 | **推荐** | 不推荐 |

## 三、设计最佳接入位置

### 3.1 方案 X：QueryTranslator 内部增强

`_concepts_for` 内部直接实现最长匹配（把 `split()` 换成 `segment()`）。

- **优点**：改动最小（单文件），调用链不变。
- **缺点**：切分逻辑与翻译逻辑耦合在 `QueryTranslator` 内；切分逻辑难以**独立单测**（需经 `translate_concepts` 间接测）；后续若切分规则复杂化（停用词、多词典）会膨胀 `QueryTranslator`。

### 3.2 方案 Y：新增 ConceptSegmenter（**推荐**）

新增 `services/concept_segmenter.py`，纯逻辑模块：

```python
class ConceptSegmenter:
    def __init__(self, dictionary: set[str] | None = None) -> None:
        self._dict = dictionary or set(TERMS.keys())

    def segment(self, text: str) -> list[str]:
        """词典最长匹配切分，返回概念词列表。"""
```

`QueryTranslator._concepts_for` 改为调用 `ConceptSegmenter().segment(expanded.original)`，再逐词元查 `TERMS`。

- **优点**：单一职责（切分归切分、翻译归翻译）；`ConceptSegmenter` 可**独立单测**（直接测 `segment()`）；与项目既有纯逻辑模块模式一致（`QueryExpansion`/`QueryTranslator`/`QueryBuilder` 各自独立）；后续可扩展（停用词、多词典、领域库）。
- **缺点**：多一个文件；`_concepts_for` 需改一行调用。

### 3.3 对比与推荐

| 维度 | 方案 X（内部增强） | 方案 Y（新增 ConceptSegmenter） |
| --- | --- | --- |
| 改动面 | 小（单文件） | 中（新增 1 文件 + 改 1 行调用） |
| 单一职责 | 差（切分+翻译耦合） | **好** |
| 可独立单测 | 差 | **好** |
| 后续扩展 | 差（膨胀 Translator） | **好** |
| 与既有模式一致 | 中 | **好** |

**推荐方案 Y**：新增 `ConceptSegmenter`（纯逻辑、独立单测），`QueryTranslator._concepts_for` 调用它。切分逻辑与翻译解耦，符合项目既有分层。

## 五、结论

1. **根因**：`_concepts_for` 用 `expanded.original.split()`（仅空白切分）+ `TERMS` 整词精确匹配，无最长匹配，导致无空格中文复合词不切分；
2. **推荐方案 B**：基于 `TERMS` 词典**最长匹配**切分，确定性、零依赖、对现有测试影响低，准确率取决于 `TERMS` 覆盖率；
3. **推荐接入位置**：**新增 `ConceptSegmenter`**（纯逻辑、独立单测），`QueryTranslator._concepts_for` 调用它，切分与翻译解耦；
4. **测试案例**：`太赫兹通感一体化` / `太赫兹通信` / `量子计算` 三个必测 + 有空格/单概念/空串/重复词补充；
5. **配套需求**：`通信`→`communication` 等词元需加入 `TERMS`（M2 词典扩充），否则 `太赫兹通信` 的 `通信` 仍保留中文。
