# v0.18 Phase 2.10-B 科研展示模式（Dashboard）设计

## Phase A：设计审计

---

## 1. 目标

提升首次使用体验：导师 / 同学第一次打开软件时，**30 秒内理解系统价值**。

新增「首页 / Dashboard」，一屏呈现：
系统定位 → 科研画像 → 数据统计 → 最近活动 → 快捷入口。

约束：
- 禁止修改 SearchService / Adapter / BrowserSession / Evidence 链 /
  LLM Provider / ReportService / LibraryRecord schema；
- **不重构已有主流程**。

### 2.4 关键测试表面（不可破坏）

- `tests/test_gui.py` 直接断言 MainWindow 的 `btn_*` / `label_status` / `table`
  等属性存在，且 `btn_search` 初始可用、`btn_detail` / `btn_export` 初始禁用。
- `tests/test_version.py` 断言 `VERSION == "0.9.0"`、`APP_NAME`、
  `SUPPORTED_SOURCES`、`FEATURES` 内容不变。

→ **结论：Dashboard 必须"只增不改"**：新增按钮与模块，不动既有卡片与属性。

## 3. 设计方案

### 3.1 架构：独立模块 + 新增入口按钮

```
ui/dashboard_widget.py        ← 新增（独立 UI 模块）
├── DashboardWidget(QWidget)  ← 可复用内容（含 3 个快捷入口信号）
└── DashboardDialog(QDialog)  ← 独立窗口包装（应用 theme.THEME_QSS）

ui/main_window.py             ← 仅新增 btn_dashboard + _on_open_dashboard
services/demo_provider.py     ← 新增 DemoDataProvider（只读）
version.py                    ← 新增 RELEASE_LABEL / CAPABILITIES（不改 VERSION）
ui/settings_dialog.py         ← 新增"版本 / 关于"Tab
```

选择"独立窗口"而非"嵌入首页卡片"的理由：
1. 约束要求不重构主流程；插入卡片会改变既有垂直布局与窗口高度；
2. MainWindow 已有成熟的"按钮 → 独立 QDialog"模式（论文库 / 设置 / 报告），
   沿用同一模式风险最低；
3. 独立窗口可承载更丰富的 5 段式内容，而不挤压检索区。

### 3.2 DashboardWidget 内容（5 段）

| 段 | 内容 | 数据来源 |
|----|------|----------|
| ① 系统名称 | **TJU Research Assistant** + 一句话定位 | 常量 |
| ② 科研画像摘要 | 研究方向 / 研究阶段（未设置 → 友好引导） | `ResearchProfileStore.load()` |
| ③ 统计 | 论文库数量 / AI 分析数量 / 报告数量 | `LibraryStore.stats()` + `list_summaries()` |
| ④ 最近活动 | 最近收藏论文（≤5）/ 最近生成报告（≤5） | `load_all()` 按 `saved_at` 倒序；`list_summaries()` |
| ⑤ 快捷入口 | 搜索论文 / 打开论文库 / 生成报告 | Qt Signal |

### 3.3 快捷入口信号契约

```python
class DashboardWidget(QWidget):
    search_requested  = Signal()   # → MainWindow: 聚焦检索输入
    library_requested = Signal()   # → MainWindow._on_open_library_window
    report_requested  = Signal()   # → MainWindow: 打开论文库并提示生成
```

MainWindow 连接后关闭 Dashboard，回到主流程入口——**不新增业务调用链**。

### 3.4 Demo 模式（Phase C）

`services/demo_provider.py`：

```python
class DemoDataProvider:
    @classmethod
    def papers(cls) -> list[LibraryRecord]              # 3 篇
    @classmethod
    def analyses(cls) -> list[EnhancedSummary]          # 2 份
    @classmethod
    def analysis_pairs(cls) -> list[tuple[str, EnhancedSummary]]
    @classmethod
    def report(cls) -> ResearchReport                   # 1 份
    @classmethod
    def snapshot(cls) -> dict                           # 仪表盘用聚合
```

只读保证：
- 模块级模板常量，所有访问器返回**新建副本**；
- 不调用 LibraryStore.save / ResearchReportStore.save；
- 不写入 `data/`、`runtime/`、用户真实目录。

Dashboard 通过 `demo_mode: bool` 切换数据源（演示模式 → DemoDataProvider，
正常模式 → 真实 store），用于"完整链路"展示：3 篇论文 → 2 份 AI 分析 → 1 份报告。

### 3.5 版本信息（Phase D）

`version.py` 新增（**不改** `VERSION = "0.9.0"`，避免破坏 `test_version.py`）：

```python
RELEASE_LABEL = "v0.18 RC"
CAPABILITIES: list[str] = [...]   # 能力列表（8 项：检索/分析/画像/论文库/报告/导出…）
```

`SettingsDialog` 新增第三个 Tab「版本 / 关于」：显示版本号 + 能力列表。

### 3.6 数据隔离

- Dashboard 只读 store 的既有 API，不写任何文件；
- DemoDataProvider 无写路径；
- 新增测试全部使用隔离目录（`TEST_USER_DATA_ROOT`），不触碰真实数据。
