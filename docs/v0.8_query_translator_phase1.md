## 2. 架构变化

### 2.1 新增模块

`services/query_translator.py`：

```python
TERMS = {
    "太赫兹":   {"en": ["terahertz", "THz"]},
    "通感一体化": {"en": ["integrated sensing and communication", "ISAC"]},
}
ENGLISH_SOURCES = {"IEEE Xplore"}

class QueryTranslator:
    def translate(self, expanded: ExpandedQuery, sources: list[str]) -> dict[str, str]:
        # 中文源 → 透传 expanded.query_string
        # 英文源 → _to_english(expanded)：逐词元查词典，命中替换为英文等价词，未命中保持原样
```

- **输入**：`ExpandedQuery` + `sources` 列表。
- **输出**：`{数据源: 检索串}` 字典。
- **默认透传**：未知词保持原样；非英文源（CNKI/万方）直接返回 `expanded.query_string`。
- **无 LLM**：纯规则词典，确定性、离线、可单测。

### 2.2 SearchService 接入

`search_service.py`：

```python
# __init__ 新增
self._translator = QueryTranslator()

# search() 中
queries = self._translator.translate(expanded, sources)

for source_name in sources:
    ...
    partial = adapter.search(queries[source_name], query.result_count)
```

`adapter.search(keyword, count)` 接口签名不变，只是 `keyword` 变成该数据源对应语言的检索串。

### 2.3 检索链路（Phase 1 后）

```
GUI → QueryRequest → SearchService
  → QueryExpansionService.expand → ExpandedQuery
  → QueryTranslator.translate(expanded, sources) → {CNKI: 中文串, 万方: 中文串, IEEE: 英文串}
  → AdapterRegistry → 各 Adapter.search(queries[source_name], count)
  → ResultMerger.merge → RankingService.rank
```

## 4. 对 210 测试影响

**无破坏。** 原因：`QueryTranslator` 对非英文源（CNKI/万方）默认透传 `expanded.query_string`，因此：

- `test_search_service.py:56`（adapter 收到 `Q`）、`:61`（含 太赫兹/OR/AND/理论）、`:71`（`量子计算`）等单源断言全部不变；
- 多源测试（S1/S2/S3、CNKI/万方）均使用非英文源 → 透传原串，行为与 Phase 1 前完全一致；
- `test_query_expansion.py`、`test_result_merger.py`、`test_ranking.py` 等不受影响（未改这些模块）。

新增的 9 个测试只增不减，210 原有测试全部通过。
