## 2. 敏感词命中分类复核（全部命中逐类检查）

| 模式 | 命中数 | 复核结论 |
|---|---|---|
| `api[_-]?key` | 183 | 全部为环境变量名（`TJU_INFO_LLM_API_KEY`、`DEEPSEEK_API_KEY`）、keyring 接口、扫描器规则；`api_config_manager.py` 保存配置时显式剥离 `api_key/token/authorization` 明文字段 |
| `credential` | 125 | keyring/DPAPI 后端实现（`credential_store.py`）与文档说明，无凭据值 |
| `edge_profile` | 106 | 专用 Edge Profile 路径常量与文档；Profile 目录本身在 `runtime/`（未跟踪） |
| `storage_state` | 99 | Playwright `storage_state()` API 调用与路径常量；真实 storage_state 文件未跟踪（见 §3） |
| `authorization` | 32 | `llm_provider.py:166` 在运行时拼装 Bearer 认证头（密钥仅内存注入，来自 keyring/env，不落盘）；其余为文档与扫描规则 |
| `secret` | 52 | 模块 docstring「非 secret」声明、扫描器规则；无密钥值 |
| `password` | 28 | keyring `get_password/set_password` API 与 UI `EchoMode.Password`；无明文密码 |
| `bearer` | 9 | 同 authorization，无真实 token 值 |
| `sk-…` 形态 | 4 | 全部在 `tests/test_release_data_scan.py`，为**合成测试 fixture**（`sk-` + 32 位字母序占位串），且该测试断言此类值不得进入发布产物 |

**LLM Provider 密钥链路核验**：`api_config_manager.py` 设计为「配置 JSON 只存
`api_key_env` 指向的环境变量名，密钥本体走 keyring → DPAPI `credential.dat` 回退，
仅在内存注入」。实测开发机上不存在 `credential.dat`；`runtime/summary_provider.json`
只含 `provider/base_url/model/api_key_env/credential_backend` 五个非敏感字段，无明文密钥。
