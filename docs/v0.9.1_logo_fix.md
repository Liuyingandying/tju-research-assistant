## 2. 为什么不能直接整图裁切、最终如何提取

`参考图.png`（1448×1086）是完整 UI 设计稿：校徽位于左上 Header（深蓝双环、
环形英文校名、中央盾形、下方中文校名），与标题文字、Header 渐变背景相邻，
因此不能整块矩形裁切直接使用。处理过程：

1. 4 倍放大定位 + 按行/列暗像素直方图精确定界（排除右侧标题与 Header 装饰线）：
   - 圆形边界 x ∈ [37, 116]，y ∈ [25, 106]，圆心约 (76.5, 65.5)，外半径约 41px。
2. 以圆心裁 88×88 方形，逐像素施加圆形羽化蒙版（半径 41.8、羽化 1.6px），
   圆外全透明，得到干净的可缩放圆章。
3. 产物即 `src/tju_info_retrieval/ui/assets/tju_logo.png`（88×88，ARGB32，
   圆外透明）。这是本项目唯一的二进制图片资源；图标仍全部为 QPainter 矢量绘制。

## 3. 代码改动（仅 1 个源文件 + 1 个资源 + .gitignore）

### `src/tju_info_retrieval/ui/theme.py`（唯一源码改动）

- 新增 `_emblem_source()`：模块级缓存地读取
  `Path(__file__).parent / "assets" / "tju_logo.png"`，项目相对路径，无绝对路径。
- 新增 `_tinted_emblem(src, color)`：**由同一资源**在运行时生成单色变体——
  按像素暗度映射透明度（深色笔迹不透明、浅色内底透明）后统一染成 ring 色。
  页脚深蓝底因此呈现浅色线章，与参考图页脚视觉一致，且来源仍为同一资源。
- `emblem_pixmap(size, ring)` 重写：
  - 无 `ring`（Header 54px、窗口图标 64px）：原色校徽，2x DPR 平滑缩放；
  - 带 `ring`（页脚 26px，`#cfdcf3`）：同一资源的浅色单色变体；
  - 资源缺失时回退 `_fallback_emblem`（原双环 “TJU/1895” 占位章），
    保证程序在资源异常时仍可运行。
- 函数签名 `emblem_pixmap(size: int = 48, ring: str | None = None) -> QPixmap` 不变。

### `main_window.py` —— 零改动

Header 调用 `theme.emblem_pixmap(54)`、页脚调用
`theme.emblem_pixmap(26, ring="#cfdcf3")`、窗口图标
`theme.emblem_pixmap(64)` 三个调用点原样保留，自动获得真实校徽。

### `.gitignore`

新增根目录 `参考图.png` 忽略项（文件仍在本地磁盘，未删除；
物理删除留待人工确认截图后决定）。
