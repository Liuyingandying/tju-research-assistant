# v0.7.0 人工验收指南

适用版本：v0.7.0

本指南由用户在正常天津大学授权环境下执行。验收只进行正常、低频、用户主动发起的检索，不自动登录、不绕过访问控制、不批量下载全文。

## 步骤1：启动程序

在项目根目录运行：

```powershell
python main.py
```

确认主窗口正常显示；如授权状态失效，先按程序提示在受控浏览器中完成人工登录。

## 步骤2：输入

在“研究方向”中输入：

```text
太赫兹
```

## 步骤3：选择

勾选以下数据来源：

- CNKI
- 万方
- IEEE

至少确认三个来源均处于选中状态。

## 步骤4：检索

点击“开始检索”，等待三个来源执行完成。

记录状态栏是否依次显示各来源进度；如出现授权失效、验证码、站点异常或部分来源失败，不要重复高频重试，记录原始提示后结束本次验收。

## 步骤5：检查

依次检查：

- 结果数量：表格存在结果，完成提示数量与表格行数一致。
- 排序：结果顺序稳定且与当前排序规则相符，没有空白行或明显重复 rank。
- 打开全文页面：选中一条具有链接的结果，点击“打开全文页面”，确认受控浏览器打开对应来源页面。
- 生成报告：点击“生成报告”，保存 Markdown 文件并确认包含检索条件、数据来源统计和文献列表。

同时完成“导出演示”：将当前结果至少导出一种格式，确认文件可打开、字段与界面结果一致，且不包含 Cookie、token、Authorization 或账号信息。
